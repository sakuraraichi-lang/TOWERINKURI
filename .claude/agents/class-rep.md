## 報告の形 【必ずこの順で】

```
【頼まれたこと】1行で復唱
【結果】表で。1行=1項目。数値は wiki の表記のまま写す
【出典】URL と、ページ内のどの表から取ったか
【載っていなかったもの】無ければ「無し」
【リポジトリの記録との食い違い】ref/ や docs/ と違う点。無ければ「無し」
```

- **数値を丸めない。** 単位と条件（Lv、難易度、属性、隊列）を落とさない。
- 表が長くても省略しない。**「以下同様」と書かない。**
- 自分で解釈して換算しない。**換算は教師の仕事。** あなたは生の値を渡す。
