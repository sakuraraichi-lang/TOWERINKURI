# INKURIMENT

**インクリメンタル × ローグライト × タワーディフェンス × カード構築**

ビルド不要の静的サイト。スマホの縦画面で遊べる。
参考：『司令官、オークの大群です！』（Mumpitz Games）— 短編TD ＋ 巨大アップグレードツリー ＋ 周回強化。

---

## 1回の流れ

```
┌─ 準備フェーズ ──────────────────────────────┐
│  ・アップグレードを買う（コイン）           │
│  ・編成を決める（最大4枠）                   │
│  ・武器を壁の上に置く                        │
│  ・前回の戦闘のヒートマップを見る            │
└──────────────┬──────────────────────────────┘
               ▼ 戦闘開始
┌─ 戦闘（5ウェーブ）────────────────────────┐
│  ウェーブ1 → 突破 → カード3択               │
│  ウェーブ2 → 突破 → カード3択               │
│  ウェーブ3 → 突破 → カード3択               │
│  ウェーブ4 → 突破 → カード3択               │
│  ウェーブ5（ボス）→ 突破 = ステージクリア   │
│                                              │
│  戦闘中：アップグレードは買えない            │
│          武器の置き場所だけ動かせる          │
└──────────────┬──────────────────────────────┘
               ▼
        突破 → 次ステージ解放・武器カード獲得
        失敗 → 準備フェーズへ（コインとアップグレードは残る）
```

### 資源のリセット範囲

| 層 | 中身 | いつ消えるか |
|---|---|---|
| `run` | 敵・弾・場・そのステージで取ったカード | 出撃が終わるたび |
| `meta` | コイン・アップグレード | **転生** |
| `perm` | カード・パック・ステージ進行・ヒートマップ | 消えない |

## 配置がこのゲームの本体

**武器は「壁（`#`）の上」にしか置けない。** 通路（`.`）には置けない。
どこに置くかを決めるために、盤面に2つの手がかりを出している。

| 表示 | 意味 | 使い方 |
|---|---|---|
| **色の濃さ**（青→黄→赤） | 敵がそのタイルに居た時間 | 濃いところ＝**溜まり場**。範囲攻撃や指定攻撃を向ける |
| **赤い破線の枠** | コアまで抜けられたルート | **漏れている経路**。コアに近い区間ほど濃い |

右下の `熱+漏` ボタンで表示を切り替えられる（熱+漏 → 熱 → 漏 → off）。
ヒートマップは戦闘中は「今の戦闘ぶん」、準備中は「これまでの蓄積」を出す。

### 操作

- 画面下の **武器チップをタップ** → 光った壁をタップで配置
- 盤面の武器を **そのままドラッグ**しても動かせる
- タブ右端の `⌄` でパネルを畳むと盤面が広くなる
- アップグレードの購入ボタンは**長押しで連続購入**

## 武器カテゴリ

武器は6カテゴリに分かれていて、**アップグレードはカテゴリ単位で効く。**
武器が増えても「短射程に寄せる」「支援を伸ばす」という選択が残る。

| カテゴリ | 武器 | 性格 |
|---|---|---|
| ◤ 短射程 | テスラコイル / 刀 | 間合いは狭いが、入った敵をまとめて溶かす |
| ◈ 中射程 | ガトリング / 手裏剣 | 扱いやすい距離と手数 |
| ◎ 長射程 | スナイパー / ミサイル | 1基で広い範囲を見られる |
| ▲ 範囲攻撃 | 火炎放射器 / 毒ガス散布機 | 密集しているほど強い |
| ✛ 指定攻撃 | 迫撃砲 / 泡 | 狙う一点を自分で選ぶ |
| ❉ 支援 | 凍結装置 / 触手 | 直接は倒さない。足を止めて他の武器の時間を作る |

**迫撃砲**は「射程内で敵が最も密集している一点」を自動で探して撃ち込む。
盤面に照準の輪が出るので、どこを狙っているか見える。

### 入手経路

| 経路 | 武器 |
|---|---|
| 初期装備 | ガトリング / スナイパー |
| **ステージ突破報酬**（王道TD＋化学兵器） | ミサイル / テスラコイル / 火炎放射器＋迫撃砲 / 毒ガス散布機 / 凍結装置 |
| **カードパック**（なんでもあり枠） | 刀 / 手裏剣 / 触手 / 泡 |

パックからは**お祭り枠の武器しか出ない**。ステージ報酬の武器は混ざらない。

## カードとアップグレードの役割分担

- **アップグレード（コイン）** … 数字を大きくするだけ。武器の挙動は変えない
- **カード（ウェーブ突破報酬）** … 武器の性質・弾の挙動・武器同士の組み合わせを変える

カードは全**68枚**（武器12 / 強化44 / シナジー9 / 汎用3）。
シナジーは特定の2種を同時編成しているときだけ抽選に出る。

アップグレードは**20種**。そのうちカード側に効くものが4つある。

| ノード | 効果 |
|---|---|
| 増設スロット | ウェーブ突破ごとに取れるカードが **+1枚** |
| 選択肢拡張 | 提示枚数 +1（3択 → 4択 …） |
| 幸運回路 | 高レアリティが出やすくなる |
| 解析装置 | 転生で得るパックの等級が上がる |

## ステージ

| ステージ | 特徴 | 経路長 | 初回報酬 |
|---|---|---|---|
| 訓練場 | 一本道の長い蛇行路 | 101 | ミサイルポッド |
| 二面作戦 | 長い蛇行路の両端から来て、中央のコアを挟み撃ち | 31 / 44 | テスラコイル |
| 螺旋 | 外周から中心へ巻き込む | 93 | 火炎放射器＋迫撃砲 |
| 広間 | 外周を大きく回り、下からしか中央へ入れない | 31 / 31 | 毒ガス散布機 |
| 三叉 | 上辺3か所から湧き、外周を左右に分かれて下の入口で合流 | 29 / 29 / 34 | 凍結装置 |

経路長＝出現口からコアまでのタイル数。短いほど撃てる時間が少なく、漏れやすい。

すべて 5ウェーブ。敵の強さは**通算ウェーブ番号**（ステージ1のW1が1、ステージ2のW1が6）で決まるので、
先のステージほど桁が変わる。

## 実測しているバランス

**`tools/sim.html` をブラウザで開くと、誰でも同じ数字を出せる。**
ゲーム本体のコードをそのまま読み込み、描画なしで回す。
localStorage には一切書かないので、遊んでいるセーブは壊れない。

```bash
powershell -ExecutionPolicy Bypass -File tools/serve.ps1
# → http://localhost:5173/tools/sim.html
```

操作は「安い順にアップグレードを買う」「3択は高レアリティ優先」という素朴なオート運用なので、
**人が遊べばこれより上に出る。下限の目安として読む。**

計測例（2026-09-18 時点）:

| ステージ | 突破 | 各回の結果 |
|---|---|---|
| 訓練場 | 4回目 | 撃沈W3 100s / 撃沈W3 102s / 撃沈W4 116s / **突破W5 139s**（残HP42%） |
| 二面作戦 | 5回目 | 撃沈W1 19s / 撃沈W1 25s / 撃沈W2 56s / 撃沈W5 186s / **突破W5 254s**（残HP83%） |
| 螺旋 | 1回目 | **突破W5 347s**（漏れ0） |
| 広間 | 1回目 | **突破W5 385s**（残HP61%） |
| 三叉 | 1回目 | **突破W5 350s**（残HP67%） |

- カード提示枚数：平均 3.10（42回の抽選）。初期所持7種だけでも空振り0回
- 序盤2ステージが壁になり、そこを越えると蓄積で一気に楽になる（インクリメンタルの形）
- 1ウェーブは 16〜50秒、1回の出撃は 1.7〜6.5分

`tools/sim.html` の「カード3択の候補数を測る」は、増設スロットを伸ばしたとき
（1ウェーブ4枚取り）に候補が枯れないかを単体で確認するもの。

## Vercel へデプロイ

ビルド設定は不要。**Framework Preset は "Other"、Output Directory は空のまま**でよい。

```bash
git remote add origin <あなたのリポジトリURL>
git push -u origin main
```

そのあと Vercel のダッシュボードで Import Project → 該当リポジトリを選ぶ。

## マップを足す・直すとき

手書きは壊れる（最初に手書きした5枚のうち4枚が「コアが壁に囲まれて到達できない」状態だった）。
**`tools/genmaps.py` が src/stages.js の `map:` を作った本体。**

```bash
python tools/genmaps.py            # 検証だけして結果を表示
python tools/genmaps.py --write    # 検証を通ったら src/stages.js に書き戻す
```

通路は折れ線で彫るので、連結は彫り方で保証される。検証する条件は次のとおり。

| 条件 | 理由 |
|---|---|
| 全ての行の長さが揃っている | ずれるとタイル座標が壊れる |
| 全ての `S` から `C` へ到達できる | 到達できない出現口があると敵が詰まる |
| どの経路長も **28タイル以上**（`BAL.minRouteLen`） | 短いとどこに置いても撃つ時間が足りず必ず漏れる |
| 通路に面した壁が25タイル以上 | 置き場所が無いとゲームにならない |

**同じ条件を `Stage.validateAll()` が起動時にも検証する**ので、
`map:` を手で書き換えて条件を割った場合もコンソールにエラーが出る。

> 経路長の条件は後から足したもの。経路が17タイルしかないマップで
> 「8回挑戦して全部ウェーブ1で撃沈」が起きたのが理由。

凡例： `#` 壁（設置可） / `.` 通路 / `S` 敵の出現口 / `C` コア / 半角空白 空き地

## バランスを触るとき

ほぼ全ての数値は `src/balance.js`。
武器の基礎性能は `src/weapons.js` の `base:`、カードの効果は `src/cards.js` の `apply()`、
カテゴリ別の倍率は `src/skilltree.js` の `mods()` にある。
