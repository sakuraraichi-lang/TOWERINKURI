# INKURIMENT

**インクリメンタル × ローグライト × タワーディフェンス × カード構築**

ビルド不要の静的サイト。スマホのブラウザで遊べる。

---

## コアループ

```
敵を倒す → ◈コイン + 経験値
   ◈コイン   → スキルツリー（数字を大きくする）
   経験値     → レベルアップ → 3択カード（武器の挙動を変える）
   ↓
より高いウェーブへ → 拠点破壊でラン終了（コインとスキルは残る）
   ↓
節目ウェーブ / 転生 / ミッション → カードパック
   ↓
カードコレクション拡張（永久）→ 次のランのビルド選択肢が増える
```

### 資源のリセット範囲

| 層 | 中身 | いつ消えるか |
|---|---|---|
| `run` | 敵・弾・取得カード・経験値 | ラン終了 |
| `meta` | コイン・スキルツリー | **転生** |
| `perm` | カードコレクション・パック・実績・自己ベスト | 消えない |

### 役割分担（重複させない）

- **インクリメンタル（スキルツリー）** … 数字を大きくするだけ。武器の挙動は変えない
- **カード** … 武器の性質・弾の挙動・武器同士の組み合わせを変える

---

## 遊び方

- 中央の拠点を守る。武器は自動で攻撃する
- **武器は戦場で直接ドラッグして動かせる**（拠点から一定範囲内）
- 下部タブ：スキル／編成／コレクション／パック／転生
- スキルの購入ボタンは**長押しで連続購入**

---

## ローカルで動かす

Node も Python も不要。PowerShell だけで動く静的サーバを同梱してある。

```bash
powershell -ExecutionPolicy Bypass -File tools/serve.ps1
```

→ http://localhost:5173/

（`index.html` を直接ダブルクリックしても動くが、一部ブラウザでは
`file://` の制限でセーブが効かないことがある）

## Vercel へデプロイ

ビルド設定は不要。**Framework Preset は "Other"、Output Directory は空のまま**でよい。

### A. Vercel CLI から

```bash
npm i -g vercel
vercel
```

初回は対話でプロジェクト名などを聞かれる。本番反映は:

```bash
vercel --prod
```

### B. GitHub 連携から

```bash
git init && git add -A && git commit -m "INKURIMENT prototype"
git remote add origin <あなたのリポジトリURL>
git push -u origin main
```

そのあと Vercel のダッシュボードで Import Project → 該当リポジトリを選ぶ。
以降は push するたびに自動デプロイされる。

`vercel.json` にキャッシュとセキュリティヘッダだけ入れてある。

## ファイル構成

```
index.html        エントリ。script は素の <script>（ビルド不要）
style.css         スマホ縦持ち優先。横長・PCでは左右2カラム
vercel.json       静的ホスティング設定
tools/serve.ps1   ローカル試遊用の静的サーバ
src/
  util.js         数値整形・乱数・ベクトル
  balance.js      全ての調整ノブ（バランスはここだけ見ればいい）
  weapons.js      武器4種の定義と発射処理
  cards.js        カード31枚（武器4 / 強化20 / シナジー4 / 汎用3）
  skilltree.js    インクリメンタル側のスキル12種
  packs.js        カードパックとミッション
  state.js        セーブデータ・ラン生成・転生
  combat.js       敵・弾・当たり判定・ウェーブ進行
  render.js       Canvas描画
  ui.js           DOM側UI（HUD・3択・開封・コレクション）
  main.js         起動・ゲームループ・タッチ入力
```

---

## バランスを触るとき

ほぼ全ての数値は `src/balance.js` に集めてある。
武器の基礎性能は `src/weapons.js` の `base:`、
カードの効果は `src/cards.js` の `apply()` にある。

## 現状の簡略化（仕様書からの差分）

1. **武器の配置** … 自由配置ではなく「拠点から半径250以内をドラッグで移動」
2. **初期所持カード** … ガトリングとスナイパーのみ。ミサイル・テスラはパックから
3. **敵の種類** … grunt / swift / tank / boss の4種のみ
