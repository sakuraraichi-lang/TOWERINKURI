# INKURIMENT

**インクリメンタル × ローグライト × タワーディフェンス × カード構築**

ビルド不要の静的サイト。スマホの縦画面で遊べる。
参考：『司令官、オークの大群です！』（Mumpitz Games）— 短編TD ＋ 巨大アップグレードツリー ＋ 周回強化。

---

## 1回の流れ

```
┌─ ビルドフェーズ ────────────────────────────┐
│  ・アップグレードを買う（コイン）           │
│  ・編成を決める（武器の「種類」を4つ）      │
│  ・ユニットを地面に置く／向きと射界を決める │
│  ・前回の戦闘のヒートマップを見る           │
└──────────────┬──────────────────────────────┘
               ▼ 戦闘開始
     ウェーブ1 → 突破 → カード3択 → ビルドフェーズ
     ウェーブ2 → 突破 → カード3択 → ビルドフェーズ
     ウェーブ3 → 突破 → カード3択 → ビルドフェーズ
     ウェーブ4 → 突破 → カード3択 → ビルドフェーズ
     ウェーブ5（ボス）→ 突破 = ステージクリア
               ▼
        突破 → 次ステージ解放・武器カード獲得
        失敗 → ビルドフェーズへ（コインとアップグレードは残る）
```

**ウェーブとウェーブの間は必ずビルドフェーズに戻る。** 次のウェーブは自動では来ない。
そこで置き直し、向きを変え、射界を絞り直す。

| いつ | できること |
|---|---|
| ビルドフェーズ（戦闘前・ウェーブ間） | アップグレード購入 / 編成変更 / 設置・撤去・向き・射界 |
| 戦闘中（ウェーブ進行中） | **何も動かせない**。見ているだけ |

### 結果と報酬

| 結果 | 得られるもの |
|---|---|
| 負け（ライフ0） | そのランで倒したぶんのコイン。**負けてもアップグレードは進む** |
| 生存（5ウェーブ凌ぐ） | 次ステージ解放。初回は武器カード |
| **完璧クリア（1体も通さない）** | **カードパック**（初回はレアパックも） |

負けても前に進み、生き残れば次へ行き、**完璧に守り切ったときだけパックが出る。**
完璧クリアは「敵を全滅させる配置と武器の組み合わせ」を考える枠として置いてある。

### ライフ

コアのHPではなく**ライフ**。抜けられた敵1体につき1減る（ボスは5）。
0になった時点で失敗。HPだと後半に数字を積んで漏らし放題になるので、**体数で数える**。

### 資源のリセット範囲

| 層 | 中身 | いつ消えるか |
|---|---|---|
| `run` | 敵・弾・場・そのステージで取ったカード | 出撃が終わるたび |
| `meta` | コイン・アップグレード | **転生** |
| `perm` | カード・パック・ステージ進行・配置・ヒートマップ | 消えない |

## 配置がこのゲームの本体

### ユニットは何基でも置ける

編成するのは武器の**種類**（4つ）。**同じ武器を上限まで何基でも置ける。**
上限は武器ごとに違う（ガトリング6／スナイパー4／迫撃砲2 …）。
アップグレード「増設基盤」でどの武器も +1 基ずつ増える。

画面下のバーに `GAT 3/6` のように **配置済 / 上限** が出る。

### 射界は「正面の扇」

ユニットは**自分が向いている扇の中しか攻撃しない。** 向きはプレイヤーが決め、戦闘中は動かない。

- **扇を絞る** … 弾が一点にまとまる（集弾率 最大100%）。ただし守備範囲は狭い
- **扇を広げる** … 広い範囲を1基で見られるが、**弾が扇いっぱいに散る**（集弾率 最低45%）

弾は扇の広さに比例して左右にばらけるので、広げるほど動く敵から逸れる。
即着の武器（テスラ・凍結など）は逸れようが無いので、代わりに出力が散って1体あたりが落ちる。
**絞ると効くが範囲が狭い、広げると守れるが薄い。その配分が配置そのもの。**
複数のユニットの扇を別々の角度から同じ場所へ重ねると、十字砲火になる。

### 操作

| やりたいこと | 操作 |
|---|---|
| 置く | 下のバーで武器を選ぶ → 光った地面をタップ |
| 選ぶ | 置いてあるユニットをタップ |
| 向きを変える | 選んだ状態で盤面をなぞる（ドラッグ） |
| 射界（集弾率）を変える | `◀狭` / `広▶` |
| 撤去 | `撤去`（在庫が戻る） |

盤面を広く使いたいときは、タブ右端の `⌄` でパネルを畳む。

### 置き場所を決める手がかり

| 表示 | 意味 |
|---|---|
| **色の濃さ**（青→黄→赤） | 敵がそのタイルに居た時間＝**溜まり場** |
| **赤い破線の枠** | 抜けられた**漏れルート**（コアに近い区間ほど濃い） |

右下の `熱+漏` で 熱+漏 → 熱 → 漏 → off と切替。
戦闘中は今の戦闘ぶん、ビルドフェーズはこれまでの蓄積を出す。

## 武器カテゴリ

武器は6カテゴリに分かれていて、**アップグレードはカテゴリ単位で効く。**

| カテゴリ | 武器 | 性格 |
|---|---|---|
| ◤ 短射程 | テスラコイル / 刀 | 間合いは狭いが、入った敵をまとめて溶かす |
| ◈ 中射程 | ガトリング / 手裏剣 | 扱いやすい距離と手数 |
| ◎ 長射程 | スナイパー / ミサイル | 1基で広い範囲を見られる |
| ▲ 範囲攻撃 | 火炎放射器 / 毒ガス散布機 | 密集しているほど強い |
| ✛ 指定攻撃 | 迫撃砲 / 泡 | 狙う一点を自分で選ぶ |
| ❉ 支援 | 凍結装置 / 触手 | 直接は倒さない。足を止めて他の武器の時間を作る |

**迫撃砲**は射界の中で敵が最も密集した一点を自動で探して撃ち込む（照準の輪が出る）。

### 入手経路

| 経路 | 武器 |
|---|---|
| 初期装備 | ガトリング / スナイパー |
| **ステージ突破報酬**（王道TD＋化学兵器） | ミサイル / テスラコイル / 火炎放射器＋迫撃砲 / 毒ガス散布機 / 凍結装置 |
| **カードパック**（なんでもあり枠） | 刀 / 手裏剣 / 触手 / 泡 |

## カードパックの入手経路

コインでは買えない。手に入るのは4つだけ。

| 経路 | 内容 |
|---|---|
| ステージ初回突破 | そのステージに紐づいた分野のパック |
| **初回の完璧クリア** | 同じ分野のパックがもう1つ（2回目以降も1つ） |
| ミッション | 実績ごとに指定の分野 |
| 転生 | 突破した深さに応じて（下記） |

### パックは分野で分かれている

1つのパックに全カードが入っているわけではない。**浅いところを掘っても奥の分野は出ない。**

| パック | 中身 | 解放 |
|---|---|---|
| 基本パック | 汎用カード＋初期装備（ガトリング・スナイパー）の強化 | 最初から |
| 兵装パック | 短射程・中射程・長射程。刀と手裏剣もここ | 1ステージ突破 |
| 化学パック | 範囲攻撃・指定攻撃・支援。触手と泡もここ | 2ステージ突破 |
| 連携パック | シナジー専用（エピック以上1枚確定） | 3ステージ突破 |

ステージごとの分野： 訓練場=基本 / 二面作戦=兵装 / 螺旋=兵装 / 広間=化学 / 三叉=連携

### 転生とパック掘り

**転生するとステージの突破状況も戻る。** もう一度突破すれば初回報酬と初回完璧クリアの報酬を
取り直せるので、転生を繰り返してパックを掘れる。
ただし「1ステージ突破して即転生」が最高効率にならないようにしてある。

- 深さ1では**そもそも転生できない**（最低2ステージ）
- もらえるパック数は **突破ステージ数の1.7乗**。深さ2で3個、深さ5で15個
- 出る分野は「そこまでに突破したステージの分野」に限られる

実測（同じ転生4回で比較）:

| やり方 | パック合計 | 掘れた分野 |
|---|---|---|
| 浅く（2ステージ）×4回 | 12個 | 基本・兵装のみ（化学0 / 連携0） |
| 奥まで（5ステージ）×4回 | **60個** | 全分野 |

パックの解放条件だけは「到達した深さ」で覚えているので、転生しても閉じない。

## カードとアップグレードの役割分担

- **アップグレード（コイン）** … 数字を大きくするだけ。武器の挙動は変えない
- **カード（ウェーブ突破報酬）** … 武器の性質・弾の挙動・武器同士の組み合わせを変える

カードは全**68枚**（武器12 / 強化44 / シナジー9 / 汎用3）。
アップグレードは**21種**。そのうち枠を増やすものが5つある。

| ノード | 効果 |
|---|---|
| 増設基盤 | どの武器も**設置できる数 +1 基** |
| 増設スロット | ウェーブ突破ごとに取れるカードが +1 枚 |
| 選択肢拡張 | 提示枚数 +1（3択 → 4択 …） |
| 幸運回路 | 高レアリティが出やすくなる |
| 解析装置 | 転生で得るパックの等級が上がる |

## ステージ

15×21タイル（1タイル40px）。`#` の地面は**どこでも置ける**。

| 順 | ステージ | 特徴 | 出現口 | 経路長 | 初回報酬 |
|---|---|---|---|---|---|
| 1 | 訓練場 | 大きなZ字。斜めの区間があり、内側から2方向へ射線が通る | 1 | 45 | ミサイルポッド |
| 2 | 螺旋 | 外周から中心へ。輪と輪の間から内外どちらにも撃てる | 1 | 61 | 火炎放射器＋迫撃砲 |
| 3 | 広間 | 中央の島をぐるりと回る。島の上にも外周にも置ける | 2 | 23 / 23 | 毒ガス散布機 |
| 4 | 二面作戦 | 長い蛇行路の両端から来る。脚と脚の間から左右に撃てる | 2 | 29 / 29 | テスラコイル |
| 5 | 三叉 | 3方向から来て中央で合流。合流点のまわりが全部地面 | 3 | 23 / 23 / 24 | 凍結装置 |

**並び順は実測で決めてある。** 蓄積を排除して同じ戦力・同じ敵の強さで測ると、
出現口が多いほど、経路が短いほど難しい。

| ステージ | 同条件での結果 |
|---|---|
| 訓練場 | 突破（漏1） |
| 螺旋 | 突破（漏1） |
| 広間 | 突破（漏22） |
| 二面作戦 | **撃沈**（漏41） |
| 三叉 | **撃沈**（漏42） |

奥のステージほど戦力を貯めて到達するので、難しいマップを奥に置いている。

すべて5ウェーブ。敵の強さは**通算ウェーブ番号**（ステージ1のW1が1、ステージ2のW1が6）で決まる。

## 難易度設計の考え方

このゲームは**インクリメンタル**なので、次のことは**不具合ではなく正常**として扱う。

- 数値が桁ごと大きくなる（100 → 1,000 → 1,000,000 …）
- 過去に苦戦したステージが、成長後は一瞬で抜けられる
- 後半ほど敵が桁違いに強くなる
- 武器やカードが増えてプレイヤー戦力が跳ね上がる

見るべきは絶対値ではなく **比** ―― 敵の総HP ÷ プレイヤーDPS ＝「倒し切るのに要る秒数」。
目的は「毎ウェーブを適正難度に保つ」ことではなく、
**「成長した結果、以前より先へ進める」という因果を成立させること**。

## 観測ツール `tools/sim.html`

ゲーム本体のコードをそのまま読み込み、描画なしで回す。localStorage には書かない。

```bash
powershell -ExecutionPolicy Bypass -File tools/serve.ps1
# → http://localhost:5173/tools/sim.html
```

| ボタン | 何が出るか |
|---|---|
| 実測する | ステージごとの突破までの回数（複数周の中央値）と、突破時点の戦力 |
| **成長曲線を見る** | ウェーブごとの 敵1体HP / 敵数（上限に当たると赤） / 敵の総HP / 実測DPS / **削る秒数** / **湧き切る秒数** / 実際の秒数 / 漏れ / コイン毎秒 |
| **ビルド差を見る** | 標準・強力・範囲支援・非効率 の4編成で、どこまで到達するか |
| カード3択の候補数を測る | 候補が枯れないか |

### 測定器そのものに3つ欠陥があった（2026-09-19 / commit 06c7d6d）

**先に測定器を疑う必要があった。**下の数値はすべて、直したあとの測定器で取り直したもの。

| 欠陥 | 何が起きていたか |
|---|---|
| 自動配置が通路に張り付いていた | 候補が「通路に隣接するタイル」だけだったので、射程430のスナイパーと射程100の刀が同じ場所から撃っていた。**射程差が測定上まるごと消えていた** |
| 「強力」と「標準」が同じ編成だった | 武器4種が完全に同一で順番だけ違い、同じものを2回測っていた。「非効率」も2種しかなく、「射程が短い」と「種類が少ない」が混ざっていた |
| 打ち切りを「失敗」と数えていた | ウェーブが長くなると1ステージが時間上限を超え、倒せているのに失敗扱いで15回やり直していた |

旧配置は `autoPlaceHug` として残してあり、`PLACE_MODE` で新旧を切り替えて比べられる。

### ビルド差の実測（新旧の配置で同じ条件を通した）

| ビルド | 旧配置（通路に張り付き） | 新配置（射線で選ぶ） |
|---|---|---|
| 標準（射程を散らす） | 5/5 … 1, 5, 5, 2, 3 | **5/5** … 1, 4, 3, 1, 2 |
| 強力（シナジー狙い） | 2/5 … 1, 4, 打切 | 2/5 … 1, 5, 打切 |
| 範囲・支援寄り | 2/5 … 1, 3, 未突破 | **5/5** … 1, 2, 2, 1, 1 |
| 非効率（短射程だけ） | 1/5 … 1, 打切 | 2/5 … 1, 1, 打切 |

> **かつてここには「非効率な編成がいちばん少ない回数で抜けている、ビルドの強弱が逆転している」と書いてあった。**
> 測定器を直したら再現しなくなった。ゲーム側ではなく測定側の問題だった。
>
> 新配置では順当に、標準と範囲・支援が全ステージを抜け、短射程だけの編成は2ステージで止まる。
> 「強力（シナジー狙い）」が3ステージ目で打ち切りになるのは、下の②が原因で測定自体が通らないため。

### 成長曲線の実測（2026-09-19 / 標準編成・新配置）

「削る秒数」＝敵の総HP ÷ 実測DPS。「湧き秒数」＝最後の1体が湧き終わるまで。

| ステージ | 通算W | 敵1体HP | 敵数 | 敵の総HP | 実測DPS | 削る秒数 | 湧き秒数 | 実際の秒数 |
|---|---|---|---|---|---|---|---|---|
| 訓練場 | 1 | 19 | 33 | 627 | 86 | 7.3s | 7.0s | 18.0s |
| 訓練場 | 5 | 54 | 69 | 3.74K | 158 | 23.7s | 13.0s | 24.0s |
| 螺旋 | 6 | 95 | 162 | 15.4K | 658 | 23.4s | **29.7s** | 38.7s |
| 螺旋 | 10 | 272 | 237 | 64.5K | 2.27K | 28.4s | **38.4s** | 66.4s |
| 広間 | 11 | 477 | 344 | 164K | 5.77K | 28.4s | **54.1s** | 59.3s |
| 広間 | 15 | 1.36K | 445 | 607K | 14.9K | 40.6s | **62.0s** | 69.8s |
| 二面作戦 | 16 | 2.39K | 571 | 1.37M | 61.3K | 22.3s | **77.2s** | 84.0s |
| 二面作戦 | 20 | 6.83K | **600** (693) | 4.10M | 275K | 14.9s | **71.8s** | 80.8s |
| 三叉 | 25 | 34.3K | **600** (966) | 20.6M | 449K | 45.8s | **61.6s** | 65.7s |

（敵数の括弧内は、上限が無ければ出ていたはずの数）

**見えた曲線の折れ:**

1. **ウェーブの長さを決めているのは戦闘ではなく、敵が湧き切るのを待つ時間。**
   通算W6で湧きが削りを追い越し、W16では湧き77.2秒に対して削り22.3秒――**3.5倍**。
   W20では**4.8倍**。**1ウェーブの9割が「敵が出てくるのを待っているだけ」の時間**になっている。
   1周（全5ステージを1回ずつ突破）で約24.5分、ステージ別に 1.7 / 4.7 / 5.4 / 6.9 / 5.8 分

2. **敵数の上限600は通算W17から効き始める**（`BAL.waveCountMax`）。
   W25では966体のはずが600体で、**38%が抑えられている**。
   ただし削る秒数は全体を通して22〜50秒の帯に収まっており、
   ステージHP係数（×1.35^ステージ）が相殺している。**今のところ実害は小さい**

> **訂正:** 以前ここには「敵数が頭打ちになるので要る秒数が 45.4s → 19.3s に落ちる」と書いていた。
> その数字は旧配置＋打ち切り誤判定の条件で出たもので、測定器を直したら再現しない。

## マップを足す・直すとき

手書きは壊れる（最初に手書きした5枚のうち4枚が「コアが到達不能」だった）。
**`tools/genmaps.py` が src/stages.js の `map:` を作った本体。**

```bash
python tools/genmaps.py            # 検証だけして結果を表示
python tools/genmaps.py --write    # 検証を通ったら src/stages.js に書き戻す
```

通路は折れ線（縦・横・斜め45度）で幅2に彫るので、連結は彫り方で保証される。

| 条件 | 理由 |
|---|---|
| 全ての行の長さが揃っている | ずれるとタイル座標が壊れる |
| 全ての `S` から `C` へ到達できる | 到達できない出現口があると敵が詰まる |
| どの経路長も **20タイル以上**（`BAL.minRouteLen`） | 短いとどこに置いても撃つ時間が足りず必ず漏れる |
| 置ける地面が90タイル以上 | 置き場所が無いとゲームにならない |
| **十字砲火を組める地面が40タイル以上** | 一直線の廊下だと全ユニットが同じ方向を向くことになる |

「十字砲火を組める地面」＝ 2本以上の通路が **60度以上ひらいた方向** に、6タイル以内で見える地面。

到達可能性と経路長は `Stage.validateAll()` が**起動時にも検証する**（コンソールにエラーが出る）。

凡例： `#` 地面（設置可） / `.` 通路 / `S` 敵の出現口 / `C` コア / 半角空白 障害物
