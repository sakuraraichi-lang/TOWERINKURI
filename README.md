# INKURIMENT

**インクリメンタル × ローグライト × タワーディフェンス × カード構築**

ビルド不要の静的サイト。スマホの縦画面で遊べる。

---

## コアループ

```
敵が通路を通ってコアへ向かう → 壁に置いた武器で倒す
   ◈コイン   → スキルツリー（数字を大きくする）
   経験値     → レベルアップ → 3択カード（武器の挙動を変える）
   ↓
より高いウェーブへ → コア破壊でラン終了（コインとスキルは残る）
   ↓
ステージ突破 / 節目ウェーブ / 転生 / ミッション → 武器カード・カードパック
   ↓
カードコレクション拡張（永久）→ 次のランのビルド選択肢が増える
```

### 資源のリセット範囲

| 層 | 中身 | いつ消えるか |
|---|---|---|
| `run` | 敵・弾・場・取得カード・経験値 | ラン終了 |
| `meta` | コイン・スキルツリー | **転生** |
| `perm` | カードコレクション・パック・ステージ進行・実績 | 消えない |

### 役割分担（重複させない）

- **インクリメンタル（スキルツリー）** … 数字を大きくするだけ。武器の挙動は変えない
- **カード** … 武器の性質・弾の挙動・武器同士の組み合わせを変える

## ステージと配置

**武器は「壁（`#`）の上」にしか置けない。** 通路（`.`）には置けない。
マップはステージごとに違うので、**どこに置くかがそのまま攻略**になる。

| ステージ | 突破ウェーブ | 特徴 | 初回報酬 |
|---|---|---|---|
| 訓練場 | W10 | 一本道の長い蛇行路 | ミサイルポッド |
| 十字路 | W20 | 出現口2つ。合流後が短い | テスラコイル |
| 螺旋 | W30 | 外周から中心へ巻き込む | 火炎放射器 |
| 広間 | W40 | 中央の部屋は下からしか入れない | 毒ガス散布機 |
| 三叉 | W55 | 出現口3つ | 凍結装置 |

### 操作

- 画面下の **武器チップをタップ** → 光った壁をタップで配置
- 盤面の武器を **そのままドラッグ**しても動かせる
- タブ右端の `⌄` でパネルを畳むと、盤面が広くなる
- スキルの購入ボタンは**長押しで連続購入**

## 武器11種と、その入手経路

| 経路 | 武器 |
|---|---|
| 初期装備 | ガトリング / スナイパー |
| **ステージ突破報酬**（王道TD＋化学兵器） | ミサイル / テスラコイル / 火炎放射器 / 毒ガス散布機 / 凍結装置 |
| **カードパック**（なんでもあり枠） | 刀 / 手裏剣 / 触手 / 泡 |

パックからは**お祭り枠の武器しか出ない**。ステージ報酬の武器がパックに混ざることはない。

カードは全**63枚**（武器11 / 強化41 / シナジー8 / 汎用3）。
シナジーは特定の2種を同時編成しているときだけ3択に出る。

## ローカルで動かす

Node も Python も不要。PowerShell だけで動く静的サーバを同梱してある。

```bash
powershell -ExecutionPolicy Bypass -File tools/serve.ps1
```

→ http://localhost:5173/

## Vercel へデプロイ

ビルド設定は不要。**Framework Preset は "Other"、Output Directory は空のまま**でよい。

### GitHub 連携（推奨）

```bash
git remote add origin <あなたのリポジトリURL>
git push -u origin main
```

そのあと Vercel のダッシュボードで Import Project → 該当リポジトリを選ぶ。
以降は push するたびに自動デプロイされる。

### Vercel CLI から

```bash
npm i -g vercel
vercel --prod
```

## マップを足す・直すとき

`src/stages.js` の `map:` は **行の長さを揃え、必ず全ての `S` から `C` へ到達できる**
必要がある。起動時に `Stage.validateAll()` が走り、壊れていればコンソールにエラーが出る。

凡例： `#` 壁（設置可） / `.` 通路 / `S` 敵の出現口 / `C` コア / 半角空白 空き地

## バランスを触るとき

ほぼ全ての数値は `src/balance.js`。
武器の基礎性能は `src/weapons.js` の `base:`、カードの効果は `src/cards.js` の `apply()`。
