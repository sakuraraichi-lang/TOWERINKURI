# アセンションの作り直し ―― 設計の案（2026-10-06・相談用）

> もとはユーザーの指示書 `docs/ASCENSION-ORDER-2026-10-06.md`（原文）。**決めたことは無い。**「アセンションについて一回で決めずにかなり話し合って決めよう」に従い、形の案と問いを出す。数字は形が決まってから測って決める。
> 最優先は指示書の「**100を1に圧縮する**」（敵7,000匹の放置 → 精鋭70匹／パック1周300枚 → 3パック）。

## 0. いまの形（数値は `src/balance.js`）

| | いま | 指示書の問題 |
|---|---|---|
| 敵の数 | 章ごとに増え、上限で切らない（`waveCountGrowth` 1.01・誘引の段 `ascLureStep` 0.25 を5レベルごと） | ① 総数は多いが一度に出る量が少なく、遅延になっている |
| 敵の種類 | 第30章までの8種＋ボス3体（5章ごと・`ascWallMul` ×30 の壁） | ② 単調 |

| パック | レベルごとに 20×1.5^Lv 個（`ascPackBase`・`ascPackGrowth`） | ③ 1回のクリアで数百枚・開けるのが作業 |

## 1. 敵を圧縮する（①）

**案 1-A：数の上限を置き、超えた分を「上位の敵」にまとめる**
- 1ウェーブの数に上限 N（例：70）を置く。HP の総量は変えず、超えた分は k 体を1体にまとめた**上位の敵**にする（HP ×k・体が大きい・少し遅い）
- 上位の敵は段を持つ（例：×10 の「精鋭」・×100 の「重装」）。名前は世界観に合わせて付ける
- 効くもの：群れに強い武器（範囲・貫通）より、1体に強い武器（単体・レート）の価値が上がる → 編成の選び方が変わる
- 測ること：同じ章で「いまの形」と「上限 N」の漏れと1章の秒（重さが減るか・難しさが保たれるか）

**案 1-B：ボスが雑魚に紛れる・ボスの小型版**
- 5章ごとの壁のウェーブ以外でも、ボス3体（ワーム・ルートキット・ジャマー）の**小型版**が雑魚に混ざる。仕掛けと弱点は本物と同じ、HP は小さい
- 壁の章は、雑魚と一緒に本物のボスが出る（第30章までは雑魚なしのまま）

**案 1-C：口を大幅に増やす**
- アセンションの盤だけ口を増やす（いまは最大6）。分断された広い盤（コア2つ）と組む

→ 1-A を土台に、1-B・1-C を章の特色（§2）として混ぜる案。

## 2. 章ごとの特色（②）

章ごとに1つ、固定の「特色」を付ける（盤と同じく全員同じ・乱数にしない）。
| 特色（例） | 中身 |
|---|---|
| 耐性ラッシュ | ある耐性の敵が大半を占める（特定の武器がよく効く章） |
| ボスラッシュ | ボスの小型版がウェーブごとに出る |
| 大口 | 口が多い |
| 精鋭 | 上位の敵の割合が多い・数は少ない |
| 二重コア＋ | コアが増える |
- アセンションのレベルの段ごとに、特色が重なっていく（Slay the Spire のアセンションの「段ごとに質の違う変化」・DESIGN-IDEAS §3）
- **敵の難しさを自分で組む**（DESIGN-IDEAS §3・Hades のヒート）は、この特色を出撃前に自分で足して報酬の倍率を上げる形にできる

## 3. パックを圧縮する（③④）

**案 3-A：上位パックへの交換**
- アセンションで手に入るふつうのパックは、そのまま開けもできるが、**ふつうのパック M 個＋コイン C 枚で上位パック1個**に交換できる
- コインはアセンションでも落ちる（いまは使い道が無い）→ 交換の支払いに使う。**交換レートはコインの要求数で絞る**（上位パックの稼ぎを防ぐ・指示書）
- 上位パックからは**上位カード**が出る

**案 3-B：上位カードの形（どれにするか相談）**
- (a) 新しいレア度（レジェンドの上）を作る
- (b) いまの札の「上位版」（同じ札の強化版・凸とは別に持つ）
- (c) アセンション専用の札（合成の札・連携パックの札など、§4 とつなぐ）

**アセンション専用のガチャ画面**が要る（指示書）。いまのガチャ画面（データの包みを読み込む装置）の上位版として、交換の窓（M 個＋C 枚 → 1）を足す形を案にする。演出は結果画面の方針。

## 4. 武器の合成（指示書の②・発想の段階）

- 指示書：「隣り合うように置くと合成されて一つの武器になるシステムです、高コストだが超強い、と言うそれぞれの最強が発生します」
- 10-05 の記録：「近くに合成元の武器を置くと合成されるカードの出るパック」「新しい連携パック」
- 案：**合成の札**（上位パックから出る）を持っていると、決まった2種を隣に置いたときに1基の合成武器になる（コストは2基の合計より高い）。札が無ければ合成されない＝隣の強め合い（いまの仕組み）のまま
- 合成武器の中身は2種の性格を足したもの（例：テスラ＋ガトリング＝帯電弾の機銃）。12種の組み合わせ66通りを全部作らず、少数から

## 5. 相談したいこと（決めてから測る）

1. **敵の圧縮の形**：1-A（上限 N で上位の敵にまとめる）を土台にしてよいか。N の目安（指示書の「70匹」）
2. **上位カードの形**：3-B の (a)・(b)・(c) のどれか（組み合わせも可）
3. **交換**：ふつうのパックを「開けもできる」まま交換も選べる形か、アセンションでは交換の材料にしかならない形か（指示書は「上位パックへの変換通貨にしかならず」）
4. **合成の入り方**：札（パック）から入る案でよいか、置くだけで合成される案か
5. **順番**：①敵の圧縮 → ③パックの圧縮 → ②章の特色 → ④合成、の順でよいか

## 6. 進め方（案）

1. 上の5つを決める
2. 敵の圧縮（1-A）を入れ、第31〜45章を測る（いまの形と交互・漏れ・1章の秒・重さ）
3. パックの交換と専用のガチャ画面
4. 章の特色・ボスの小型版
5. 合成

## 7. ユーザーの答え（2026-10-06）

| 問い | 答え |
|---|---|
| 敵の圧縮の土台 | **上位の敵を種類として足す**（数の上限でまとめる案ではなく、HP の多い上位の敵の種類を足し、出る割合で数を減らす） |
| 上位カードの形 | **アセンション専用の札** |

## 8. 上位の敵（案・2026-10-06・相談用）

**置き換えの決まり（案）**
- 第31章から、ウェーブの敵の一部を**上位の敵に置き換える**。上位の敵1体は雑魚 k 体ぶん（HP ×k）で、**HP の総量は変えずに数だけ減る**
- 置き換える割合はアセンションのレベル（または章）で増える。最初は ×10 の段だけ、レベルが上がると ×100 の段も混ざる
- 目安：指示書の「7,000匹 → 70匹」。高いレベルでは数が約 1/100 になるところまで
- いまの8種（パケット〜アーカイブ）の耐性・特徴はそのまま残し、上位の敵はそれと別の種類として足す

**種類（案・名前は世界観に合わせた仮）**
| 名前 | 段 | 特徴 | 何を問うか |
|---|---|---|---|
| **トロイ**（TROJAN） | ×10 | 硬くて遅い。倒すと中からパケットを数体こぼす | 1体に強い武器と、こぼれた雑魚を拾う武器の両方 |
| **ランサムウェア**（RANSOMWARE） | ×10 | 近くの敵の受けるダメージを減らす（守りの気配）。本体は普通の硬さ | 先に狙って倒す・射程の長い武器で届かせる |
| **ゼロデイ**（ZERO-DAY） | ×100 | とても硬く遅い。耐性を2つ持つ（章ごとに固定の組） | 耐性に合わせた混成 |

- 出る割合・k・特徴の強さは、形が決まってから第31〜45章で測って決める（いまの形と交互・漏れ・1章の秒・1ウェーブの数）
- 図鑑の「敵」のタブに載せる。確認室に1体ずつのボタン
- ボスの小型版（§1-B）は、章の特色（§2）として別に入れる
