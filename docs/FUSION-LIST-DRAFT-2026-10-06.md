# 合成武器の一覧（案・2026-10-06・ユーザーに見てもらう用）

> もとは `docs/FUSION-ORDER-2026-10-06.md`（合成武器企画書・原文）。ユーザー：「これはゲームの核心になる部分です、一番数が多く武器のリメイクになる部分です、またレア度はレジェンドで最も入手しにくいものとしてください」
> **案。決めたことは無い。**名前・挙動・コストは仮。足したい組み合わせ・外したいもの・名前の直しを指示してもらってから作る。

## 決まり（企画書どおり）

- **A＋B＝C**。C は **A として扱う**（A の札が乗る・A の15基の上限に数える・A の系統）。B の札は乗らない
- 合成すると A の場所に C ができ、B は消える。**コストは A＋B＋2**
- 解禁は**合成の札**（上位の連携パック・レジェンド・いちばん出にくい）。**1枚の札で1つの合成**が解禁
- 企画書の例：異界の剣（刀＋触手・8）・相反の渦（凍結＋火炎・10）・スターアサルト（ガトリング＋手裏剣・4）

**コストのめやす**（いま）：ガトリング1・手裏剣1・テスラ2・毒ガス2・レーザー3・火炎3・刀3・触手3・迫撃砲3・ミサイル4・凍結4・泡4
（相反の渦は企画書で10。式どおりなら 4＋3＋2＝9。企画書の10に合わせて「重い合成は+1」の例外を置くか、式に合わせるかは相談）

## 合成武器の札（案・2026-10-06・ユーザーに見てもらう用）

> ユーザー：「合成武器同士の連携カードや、合成武器のみのピックカードも欲しいですね」

**A. 合成武器だけの3択の札（ピック）**
- 合成武器を盤に置いているときだけ、出撃中の3択に出る。**合成武器1つにつき1枚**（24枚）。その合成武器の「らしさ」を伸ばす（例）
  - スターアサルト：星形弾が弾けたあと、破片がもう一度弾ける
  - 異界の剣：裂け目が閉じるまでの時間が伸び、触手が2本になる
  - 相反の渦：渦の中で凍った敵が燃えると、凍結が割れて大ダメージ
  - プラズマチェーン：電撃が跳ぶ数 +2
  - 収束砲：ミサイルの雨が、反射した光線の先にも降る
- レア度はエピック（合成の札そのものはレジェンド）。凸は主な1軸だけ（いまの決まり）
- 合成武器は A として扱うので、**A の札も乗る**。この札はその上に足すもの

**B. 合成武器どうしの連携の札**
- 2つの合成武器が盤にそろっているときだけ3択に出る（いまの連携の札と同じ形）。組み合わせの例（8枚から）
  - スターアサルト ＋ 散弾砲：弾の雨と星形弾が当たった敵に「被弾の印」（受けるダメージ増）
  - 異界の剣 ＋ 深淵の網：網に捕まった敵へ、裂け目から触手が伸びる
  - 相反の渦 ＋ 氷泡：凍った泡が渦に入ると爆ぜる
  - 雷雲 ＋ 共振コイル：泡と雲の間で電撃が往復する
  - 業火の霧 ＋ ナパーム：燃える溜まりの上に毒の雲が来ると爆ぜる
  - 収束砲 ＋ 誘導雷撃：着弾点どうしを電撃の線が結ぶ
  - 焔刀 ＋ 円環刃：戻ってくる刃が炎の軌跡をなぞる
  - 毒霧砲 ＋ 酸の泡：毒の雲の中の泡が酸を撒く
- レア度はレジェンド（いちばん強い連携）

3. レア度：「はい、その通りです」＝ A エピック・B レジェンド
