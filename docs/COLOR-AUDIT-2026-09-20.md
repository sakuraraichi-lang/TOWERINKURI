# 配色の棚卸し（2026-09-20）

UIを「黒 × 琥珀／橙」に作り替えたあと、**リポジトリ全体の色リテラルを機械的に数え上げて**、
残っている寒色を1つずつ分類した。`src/` `proto/` `tools/` `index.html` `style.css` を対象に
`#rrggbb` / `#rgb` / `rgb(a)()` を全件抽出している。

## 結論

**UIの飾りとしての寒色は、もう残っていない。**
残っている寒色はすべて「何かを区別するための色」で、勝手に暖色へ寄せると意味が壊れる。
下表の扱いを決めてください。

---

## A. 意味を持つので触っていない（ご判断ください）

### A-1 レアリティ — `src/balance.js:103-106`

| | 色 | |
|---|---|---|
| コモン | `#9fb2c4` 灰 | |
| **レア** | `#4aa8ff` **青** | ← 寒色 |
| エピック | `#c26bff` 紫 | |
| レジェンド | 金 | |

灰→青→紫→金は、このジャンルでほぼ共通の並びです。**青をやめると「レアだ」と伝わらなくなる**ので、
勝手に変えていません。連携パックの `#c26bff`（`src/packs.js:48`）はエピックの紫に合わせたものです。

### A-2 武器カテゴリ — `src/weapons.js:14-25`

| 短射程 | 中射程 | **長射程** | 範囲攻撃 | 指定攻撃 | **支援** |
|---|---|---|---|---|---|
| `#ff8f6a` | `#ffd24a` | `#6fe3ff` | `#ff6a2a` | `#c9a0ff` | `#7fe6ff` |

**6種類を盤面で見分けるための色**なので、全部を琥珀系にはできません。
暖色4・寒色2の配分になっています。

### A-3 武器ごとの弾の色 — `src/weapons.js`

スナイパー `#6fe3ff` / 凍結装置 `#7fe6ff` / テスラコイル `#b58bff` / 泡 `#8ad8ff` / 手裏剣 `#cdd9e8`。
**飛んでいる弾がどの武器のものか**を見分けるための色です。

### A-4 状態異常 — `src/render.js` `src/combat.js`

| 状態 | 色 | 場所 |
|---|---|---|
| 凍結した敵 | `#7fd8ff` | `render.js:392` |
| 泡に閉じ込め | `rgba(160,220,255)` `rgba(140,216,255)` | `render.js:408,410` |
| 感電 | `#d8c7ff` `#c9b3ff` `#e2d6ff` | `combat.js:377,389,598,600` |
| 冷気の爆風 | `#bff0ff` | `combat.js:230,232` / `weapons.js:177` |

「凍っている」「止まっている」を色で伝えているので、暖色にすると意味が消えます。

### A-5 試作ページの武器色 — `proto/proto.js:236,238,559,568`

スナイパー `#6fe3ff` / 凍結 `#8fd8ff`。本体と同じ理由で残しています。
