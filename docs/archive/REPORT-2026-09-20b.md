## 3. 画面の流れ（ご指示 b）

### 実測した通し（375×812 エミュレーション）

```
起動
  → ホーム：ステージ名＋スタートだけ。下のタブは6つとも 🔒
     パネルにも「まずはスタートを押して、一度戦ってみよう」しか出ない
  → スタート
  → 戦場：上部に「準備フェーズ」、右上に体力バー。それ以外は出さない
  → チュートリアル 1/5「左上の武器をひとつ選ぶ」
  → 選ぶと 2/5「光っている地面をタップして置く」（盤面が暗転し、置ける壁が光る）
  → 置くと 3/5「武器の横のバーで、向きを敵のほうへ」
  → バーを動かすと 4/5「右下の『準備完了』で始まる」
  → 押すと 5/5「あとは眺めるだけ」
  → 負ける
  → ホームに戻ると スキル / 装備 / コレクション / 転生 が解禁（パック・デッキは 🔒 のまま）
  → パックを手に入れると パック / デッキ が解禁
```

この10ステップを実際にブラウザで動かして、1つずつ確認しています。

### 起動直後の説明モーダルは**廃止しました**

ルールを1枚に全部並べたモーダルが出ていました。**ご指示の「1画面にいっぺんに詰め込まない」に真っ向から反する**ので消し、その内容はチュートリアルの5段に分けました。

### 調節バーは武器の横のポップアップに

これまで画面下のトレイに出ていて、**どの武器を触っているのか目で追えませんでした。**

- 盤面の武器の**すぐ横**に出る
- 画面からはみ出すときは**反対側へ回る**（右端の武器で実測：x=363 → ポップアップ left=155 に反転）
- 視点をなぞって動かしても**武器についていく**
- つまみを24pxにしました（これまでCSS未指定で、ブラウザ既定の細いつまみでした）
- ユニット選択中もトレイの武器チップが残るので、**続けて別の武器を置けます**

実測：向き 27°→270°、射界 39°→103°（集弾 85%→45%）がバーで動くこと、移動しても向きと射界が残ることを確認。

### 「準備完了」の位置

盤面から離した**右下に単独**で置いてあります。上のトレイ（武器チップ）とも、下のコントロール列（✕ / 速度 / 一時停止）とも離しました。**指の実機での誤爆は、まだご自身で確かめていただく必要があります。**

## 4. パックタブ＝ガチャ画面（ご指示 b の最後）

```
封を切る（大きなパックをタップ）
  → 1枚ずつめくる（タップ）

```

### 「換装」について — ここは私が設計を決めました

ご指示は「3択チョイスで**既存のスキルと入れ替えられるスキル**が出たりする」でした。
中身の決め方がご指示に書かれていなかったので、**バランスが動かない形**を選んでいます。

**換装＝今あるアップグレードの「効き方」だけを差し替える。**

| 元 | 換装後 |
|---|---|
| 給弾機構（中射程のレート ×1.07） | **収束照準**（中射程の会心率 +0.04） |
| 間合い拡張（短射程の射程 ×1.09） | **速振り**（短射程のレート ×1.07） |
| 照準計算機（長射程の会心 +0.04） | **速射砲身**（長射程のレート ×1.08） |
| 拡散増幅（範囲の効果範囲 ×1.10） | **起爆同調**（範囲の会心率 +0.04） |
| 装填補助（指定のレート ×1.08） | **遠隔誘導**（指定の射程 ×1.09） |
| 制圧出力（支援の持続 ×1.12） | **過負荷回路**（支援のダメージ ×1.12） |

- **レベル・値段・上限・解放条件・カテゴリは元のまま引き継ぎます。**
  Lv3 の給弾機構を換装すると、Lv3 の収束照準になります
- **効果量は、同じ種類を持つ既存ノードから写しています。**
  新しい数字は1つも作っていません（rate 1.07 = 給弾機構 / crit 0.04 = 照準計算機 / range 1.09 = 間合い拡張）
- **買っていないノードは候補に出ません。** 換える意味が無いので。序盤は自然と出ません
- 出る確率：基本20% / 兵装40% / 化学40% / 連携25%
- 「今は換えない」で見送れます

> **ここはご判断をいただきたいところです。** 「強さは同じで向きだけ変わる」という設計にしましたが、
> 「換装のほうが少し強い（＝引く価値がある）」ほうがガチャとして正しい、というお考えなら変えます。
> 現状は**引いても強くならない**ので、ガチャの手応えは弱いはずです。
