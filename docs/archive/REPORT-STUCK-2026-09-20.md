## 2. 詰まり①：こちらの伸びが階段になっている 【最重要】

敵は `enemyHpGrowth^5 × stageHpMul` なので**毎ステージ必ず ×5.01**。等速です。
対してこちらは：

```
×3.47  →  ×2.26  →  ×10.41  →  ×1.46
      敵より遅い      敵の2倍      敵より遅い
```

- **広間（×2.26）**は敵に半分しか追いつけていない。だから試行1回で抜けているのに窮屈
- **二面作戦（×10.41）**で一気に2倍のペースで伸びる。ここで壊れる。試行5回かかっているのは
  「抜けるまで詰まって、抜けた瞬間に過剰になる」形
- **三叉（×1.46）**はもう伸びしろが無い

### なぜ揃わないのか

伸びの源が3つあって、**それぞれ別の速さで伸びる**からです。

| 源 | 伸び方 | 止まり方 |
|---|---|---|
| 火力ノード（×1.13〜1.18/段） | **累乗**。コインがある限り無限 | 値段だけ |
| 設置枠（+1基/段） | 段ごとに一定。ただし**全強化と掛け算**になる | 踏破ステージ数（今回入れた） |
| カード（ウェーブ間の3択） | 引き次第。**倍率がバラバラ**（×1.25〜×3.2） | 出た枚数 |

3つが別々に伸びるので、**噛み合った面と噛み合わない面ができます。**
今は「二面作戦で設置枠とカードが同時に噛み合う」のが偶然起きています。

### 未解決。私の案（暫定）

> **1ステージあたりの伸びを、明示的に予算として決める。**
> 「この面を抜けたら、こちらは ×5 になる」を先に決めて、火力・設置枠・カードの
> 3つで **合計 ×5 を配分する**。今は3つが勝手に足し算されている。

数値はまだ決めていません。まず**30面ぶんの傾斜表**を作って、そこに配分する順だと考えています。

## 3. 詰まり②：コインに重みが無い 【原因は特定済み・未解決】

**1面の終わりで既に残高が次の1段の118倍。** 最後は162,100倍です。
「まとめて購入」を押すだけの画面になっています。

### 試して駄目だったこと（どちらも実測）

**(a) 段の値上がり（costG）を上げる**

| | 結果 |
|---|---|
| costG ×1.0 | 5/5突破 / コイン倍率 108〜1,625,608倍 |
| costG ×1.15 | **二面作戦で止まる** |
| costG ×1.45 | **広間で止まる** / それでも 4,179倍 |

→ **倍率は下がらないのに、先に突破できなくなる。**

**(b) ステージを踏むごとに値段の桁を上げる（`BAL.costPerStage`）**

| | 結果 |
|---|---|
| ×1（切） | 5/5突破・25.6分 / コイン倍率 128〜163,263倍 |
| ×1.8 | **3/5で止まる** / 65〜572倍 |
| ×2.6 | **2/5で止まる** / 45〜338倍 |
| ×12 | 2/5で止まる / **9〜16倍（目標帯に入る）** |

→ **「重みが出る値」と「通せる値」が重ならない。** 仕組みは入れて、今は 1（切）です。

### 原因（特定済み）

**費用側の問題ではありません。収入の伸び方が費用と「次数」が違うからです。**

- 収入 … 1ステージで **×1.2〜×19.2**（今回の実測）
- 段の値上がり … 1段ごとに **×1.3 前後**

1段買っても値段は1.3倍にしかならないのに、1面進むと収入が桁で増える。
何段買っても追いつきません。

**犯人の1つは特定して潰しました。**
「集金効率」が ×1.11/段の**累乗かつ上限なし**で、実測で Lv39・**×153倍**まで伸びていました。
加算（+0.14/段）に変えたので、いまは ×153 のような値にはなりません。

**残っている源（未着手）**

| | 1ステージあたり |
|---|---|
| 敵1体あたりのコイン（`enemyCoinGrowth 1.19`） | ×2.4 |
| 1ウェーブの敵数 | ×1.2〜1.7 |
| ボス（`bossCoinMul 34`） | 面ごとに1体 |

掛け合わせて ×3〜4。実測の ×1.2〜19.2 との差は、上の3つの**組み合わせ方**にあります。
ここはまだ分解しきれていません。

## 4. 詰まり③：ツリーの浅さ 【半分だけ直った】

| | 前 | 今 |
|---|---|---|
| ノード数 | 27 | 27 |
| **上限のあるノード** | 21 | **13** |
| 1周で上限に達した数 | 11 / 21 | **10 / 13** |

火力・射程・レート・範囲の上限を外して「値段で止める」形にしました。
**が、コインに重みが無いので（詰まり②）、値段は止める役に立っていません。**
結局まだ 13個中10個が1周で打ち止めです。

→ **詰まり②が直らないと、ツリーの深さも直りません。** ここは従属関係です。

## 5. 詰まり④：カードの入手が早い 【未着手】

| | |
|---|---|
| 1周で集まる種類 | **84種中 13〜33種**（今回は13。前回計測では32） |
| 1周で開けるパック | 10個前後 |

数字がブレるのは、**パックがミッション達成で出る**ので、その周の運で変わるためです。

レビューで「アイテムとシナジーはこのまま調整してから追加」といただいたので、
**枚数を増やす方向は止めています。** 代わりに考えているのは：

> **重複に意味を持たせる。** 同じカードが出たらそのカードのランクが上がる。
> パックの数を減らさずに、集まりきるまでの距離を伸ばせる。

未着手です。
