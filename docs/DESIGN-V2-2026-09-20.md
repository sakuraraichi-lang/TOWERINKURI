# 0. 設計の土台になった計算

## 計算1：**再攻略は、倍率では潰せません**

周回内の成長速度を実測から出すと、**戦力の倍加時間は約3.5分**です
（［実測］1周で中射程 ×133／実戦25分 → 25 ÷ log₂133）。

ここから、**「再攻略30分を8分に短縮する」のに必要な恒久倍率**は：

> **×74**

転生1回でこれを配るのは無理ですし、配れば新規ステージが全部溶けます。

### **結論：再攻略の短縮は、倍率ではなく「飛ばす仕組み」で行う。**

これがご指示3（スキップ・オート・一括）の設計上の根拠です。
便利機能ではなく、**構造上そうするしかありません。**

## 計算2：永続カード層に必要な倍率

エンディングまで **12ステージ／転生7回**［仮置き］とすると、
2周目以降は1周あたり **1.33ステージ**ずつ前進します。

ステージの壁は ×1.35/ステージ［実測：`stageHpMul`］なので、
**壁は1周あたり ×1.49 で伸びます。**

| | 倍率 |
|---|---|
| 横ばいに必要（壁に追いつくだけ） | **×1.49 / 転生** |
| 設計目標（前進＋圧倒の余裕） | **×2.2 / 転生**［仮置き］ |
| 7転生の累計 | **×250** |
| うち「追いつく」ぶん | ×11 |
| **余った23倍が「圧倒」の正体** | |

**振れ幅**：ご指示どおり、毎回 ×2.2 にはしません。
**×1.4〜×3.5 のばらつき**［仮置き］を持たせ、当たり周とハズレ周を作ります。

# 2. ステージ・階層・転生の関係

| | 何を表すか | エンディングまで | エンドレス |
|---|---|---|---|
| **ステージ** | 進行そのもの。地形と壁 | **12枚（手作り）** | 自動生成が追加 |
| **転生** | 永続カードを得る周回 | **7回**［仮置き］ | 無限 |
| **階層** | 難易度の倍率 | **使いません** | **ここで初めて使う** |

**階層を製品版で使わない理由**：12ステージ × 7転生で 5時間ぶんの長さがあります。
階層を足すと「同じ地形を難易度違いで何度も」になり、
ご指示の**「同じ作業をさせて時間を水増ししない」**に反します。

# 4. ステージ攻略報酬と転生報酬の役割分担

| | **A. ステージ攻略報酬** | **B. 転生報酬パック** | **C. 特殊パック** |
|---|---|---|---|
| **いつ** | ステージ初回突破 | 転生時 | 完全クリア／レアドロップ敵／後半スキルツリー |
| **確定性** | **確定**（何が出るか分かる） | **ランダム** | **ランダム・低確率** |
| **何が出るか** | 武器・カテゴリ・ビルド用カード | **永続パッシブ（数値）** | **挙動を変えるカード** |
| **役割** | **できることを増やす** | **速くする** | **やり方を変える** |
| **転生で消えるか** | 消えない | 消えない | 消えない |

**3つとも性質が違います。**
Aは「選択肢」、Bは「速度」、Cは「質の変化」。
Bだけだと数字が増えるだけ、AとCだけだと周回が速くなりません。

| 転生回数 | 累計枚数 | 期待倍率 | 振れ幅（下〜上） |
|---|---|---|---|
| 1 | 18 | **×2.3** | ×1.5 〜 ×3.6 |
| 2 | 39 | **×4.6** | ×3.1 〜 ×7.4 |
| 3 | 63 | **×9.0** | ×6.2 〜 ×15 |
| 4 | 90 | **×19** | ×13 〜 ×33 |
| 5 | 120 | **×42** | ×28 〜 ×75 |
| 6 | 152 | **×95** | ×62 〜 ×180 |
| 7 | 188 | **×230** | ×140 〜 ×430 |

**設計目標 ×250（§0 計算2）に着地します。**

# 7. スキップ・オート設置・自動購入の解放順

| 解放 | 条件 | 効果 | **失うもの** |
|---|---|---|---|
| **倍速 ×2** | 初回転生 | 戦闘速度 ×2 | なし |
| **配置の保存と再現** | 初回転生 | そのステージの前回配置をワンタップで再現 | なし |
| **スキルの自動購入** | 転生2回 | 準備フェーズで安い順に自動購入（上限指定つき） | なし |
| **ステージスキップ** | 転生2回 **かつ** そのステージを**3回突破済み** | 戦闘せず即突破 | **ウェーブ間のカード3択**。コインは前回突破時の8割 |
| **倍速 ×4** | 転生4回 | | なし |
| **一括突破** | 転生4回 | スキップ可能なステージを連続で処理 | 同上 |
| **自動出撃** | 転生6回 | 放置で周回 | 同上＋**完全クリア判定なし**（特殊パックが出ない） |

## 設計の芯：**スキップは「報酬を削って時間を買う」**

| | 手で攻略 | スキップ |
|---|---|---|
| 時間 | かかる | 0 |
| コイン | 満額 | **8割** |
| ウェーブ間のカード3択 | **4回** | **0回** |
| 完全クリア（特殊パック） | 狙える | **不可** |

これで **「速く回りたい周はスキップ、強くなりたい周は手で」** が両立します。
スキップが常に最適にならないので、**初回攻略の楽しさが死にません。**

**新規ステージは絶対にスキップできません**（3回突破が条件なので自動的にそうなります）。

| | 第1章（st1-4） | 第2章（st5-8） | 第3章（st9-12） |

**敵HPと敵数を分けます**（ご指示）。

| 局面 | 動かすもの | 狙い |
|---|---|---|
| ウェーブが進む | **HP** | 火力の壁 |
| ステージが進む | **数とマップの広さ** | 絵が変わる。押し合いが効く |

## 「一掃できる」を成立させる条件

**同じ割合で増やしません。**

```
新規ステージ：壁 ×1.49/周 に対して 永続 ×2.2/周  → じわじわ前進
過去ステージ：壁は動かない  に対して 永続 ×2.2/周  → 指数で圧倒
```

**過去ステージの壁が動かないこと**が、圧倒が起きる理由です。
（階層制を入れると過去ステージの壁も上がるので、圧倒が消えます。§2 で入れない理由）

# 11. エンドレスモードへの拡張方針

**エンディング後に解放。** 本編の設計を犠牲にしません。

| 仕組み | 本編 | エンドレス |
|---|---|---|
| マップ | 手作り12枚 | **自動生成**（`genexp.py` を拡張） |
| 難易度 | ステージ進行 | **階層制**（敵HP ×4／敵数 ×1.6 per 階層） |
| 永続カード | **加算主体**（飽和する＝安全） | **乗算枠を追加**（飽和を外す） |
| 上限 | st12 | 無し |

## 今のうちに入れておく拡張点

| | なぜ |
|---|---|
| 敵HP・敵数の式に**階層の係数を掛ける場所**を空けておく | 後から掛けるだけで済む |
| 永続カードの効果に **加算／乗算の型**を持たせる | エンドレス用カードを足すだけで済む |
| マップを**定義データ**として読む（今そうなっています） | 生成マップを同じ口から流せる |

**先行して作らないもの**：自動生成の本体、階層のUI、無限スケールの数値。

# 13. 実装順序と、先に検証すべきリスク

## 実装順序［仮説］

```
① 永続カード層           kind:'perm' ＋ 遺物パック ＋ 転生で残す
      ↓ 測定：2周目の突破時間が 1/2 になるか
② 周回テンポ             倍速・配置の保存・自動購入・スキップ
      ↓ 測定：4周目の再攻略で手動操作が0になるか
③ ステージ12枚とマップ改修
      ↓ 測定：実機のfps（400/800体）
④ 解放順の実装（1回に1つ）
      ↓
⑤ 特殊パック・レアドロップ敵
      ↓
⑥ 数値の詰め（ここで初めてバランス調整）
      ↓
⑦ ラスボスとエンディング
      ↓
⑧ エンドレス
```

**①と②が、このゲームのループの心臓です。** ここが動かないと他は意味を持ちません。

## 先に検証すべきリスク

| 優先 | リスク | 測り方 | 今わかっていること |
|---|---|---|---|
| **1** | **実機の描画負荷が未測定。** 第3章の800体はここに乗っています | 実機で 400 / 800 / 2000体 | PCで900体 1.15ms。**実機は不明** |
| **2** | 永続カードの加算が**後半で飽和**し、7周目の1枚が無価値になる | 30枚ごとの限界効用 | §6 の表は机上計算。要実測 |
| **3** | **スキップが強すぎて手動が消える** | スキップ周／手動周の到達差 | 報酬差（コイン8割・3択なし）で担保する設計 |
| **4** | 12枚の手作りマップの**制作コスト** | — | 既存7枚を改修＋新規5枚。生成器で検証は自動化 |
| **5** | 周回層の天井 ×133 が固定だと、後半は永続層だけが効いて**単調**になる | 各章での周回層／永続層の寄与比 | 未測定 |
| **6** | 段階解放で**序盤の3択が成立しない**（候補が2〜3枚） | 序盤の候補枚数 | 対策：同じカードの2枚目以降を候補に混ぜる（`stackLimit`/`cardWeight` で実装可） |
| **7** | ~~転生回数が9回を超えると**5〜6時間を外す**~~ **【2026-09-21】目標が3時間前後（下限）に変わり、伸びるぶんは可になったのでリスクではなくなった** | 測定器で下振れ周回 | 加算主体なので詰みはしない |

## 最後に

**この設計の一言まとめ：**

> **再攻略は倍率で潰せない（×74 必要）ので、スキップで潰す。**
> **永続カードは「新しいステージに挑む初速」に使う（×2.2/転生）。**
> **過去ステージの壁を動かさないから、圧倒が起きる。**

確定した数値は1つもありません。すべて［仮置き］で、実装後に測定器で測り直します。
