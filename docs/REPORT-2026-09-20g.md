## 2. 直った3つ（実測つき）

### 加熱暴走

撃った**回数**で溜めていたので、撃ちっぱなしにした時点で「敵がいなくても常に最大」になっていました。

- **当たっているあいだだけ**溜まるようにした
- **`BAL.heatCap` で頭打ち**にした（最大でも発射レート2.2倍）
- 重ねても増えないので、同じカードは1枚までに変えた

**実測：** 上限を壊す値（`heatMax = 99`）をわざと入れて240秒回しても、
**発射レートは 2.2倍を超えませんでした**（到達した最大は1.06倍）。

### 画面の揺れ

上限はあったのですが **26px** で、しかも撃つたびに積んでいたので、
撃ちっぱなしになった時点で常に上限に張り付いていました。

**2段にしました。**

| | 上限 | 誰が積むか |
|---|---|---|
| 日常の揺れ | **3px** | 発砲・爆発 |
| 一発ものの衝撃 | **16px** | ボス撃破・雷神・漏れ |

**実測：** 4武器を240秒回して、**最大 2.3px**。

### 触手

原因が分かりました。**「上に飛ばす」処理は書いていません。**
書いてあったのは「来た道へ戻す」で、こうなっていました。

- 道の上 → 進行方向の逆へ下がる（＝正しい）
- **道を外れた瞬間、行き先が「コアへ直通」に切り替わる**
- その逆へ下がる＝**壁を無視して、コアの真逆へまっすぐ飛ぶ**

このマップ群はコアが下なので、それが「上へ弾き飛ばす」に見えていました。
ご指摘のとおり、**出現口が上にあることに依存した挙動**になっていたわけです。

**道の上にいるあいだだけ、通れるタイルへだけ**下げるようにしました。

**実測：** 掴み1回あたり平均 **1.67タイル**押し戻す／**92%** で押し戻しが成立／
**壁の中に入ったフレームは 0回**（前は壁抜けしていました）。

## 3. 指定攻撃を作り直しました

### 何を変えたか

**この分類だけ、砲身から敵へ弾が飛ばなくなりました。**

```
プレイヤーが盤面に円を置く → その円の中のランダムな点へ砲弾が降る
```

| | |
|---|---|
| **着弾まで当たり判定がない** | 敵も壁も素通りする。**射線を持たない** |
| **だから置き場所を食わない** | スナイパーやガトリングが欲しい地面を譲れる。好きな所に置ける |
| **角度の縛りを撤廃** | 制約は射程だけ。全方位・壁の向こうでも指せる |
| **射界のつまみが、着弾円の大きさになる** | 「射界」ではなく「着弾範囲 ○○タイル」と出ます |

対象は **ミサイル・迫撃砲・泡** の3つ。ミサイルは `長射程` → `指定攻撃` へ移しました。

画面では、**破線の大円＝置ける範囲／塗った円＝着弾円／中の細い円＝1発ぶんの爆風**です。
この内外の差が、そのまま「どれだけ散るか」になります。

### 狙いを武器に持たせていた3つのシナジーを直した

「武器にどこを狙うか決めさせない」に反していたので、書き換えました。
（3つとも**実体の無いフラグ**で、説明文だけが嘘をついていた状態でした）

| | 前 | 後 |
|---|---|---|
| 曳光指示 | ミサイルが**最優先で狙い** ×1.6 | スナイパーが撃ち抜いた敵に印。**そこへ落ちたとき** ×1.6 |
| 吊るし上げ | ミサイルが**殺到し** ×2.2 | 掴まれている敵**への着弾** ×2.2 |
| 照準固定 | 迫撃砲が**必ず撃ち込む** ×1.5 | 掴まれている敵**への着弾** ×1.5 |

## 4. 【要判断】「絞ると火力が上がる」が、2武器で成立していません

ご指示のうち、**ここだけ届いていません。**正直に出します。

> 範囲を絞らないと密度が下がって火力が落ちるみたいな運用にしたい

私は**倍率を掛けずに、幾何だけで成立させよう**としました
（絞る → 同じ発射数が狭い面に落ちる → 同じ敵に重なる、という理屈）。

**1基だけを180秒動かして、4回ずつ平均した実測です。**

| つまみ | 着弾円 | **泡** | **ミサイル** | **迫撃砲** |
|---|---|---|---|---|
| 0%（最も絞る） | 爆風と同じ大きさ | **208撃破** | 29撃破 | 52撃破 |
| 50% | | 126撃破 | 21撃破 | 66撃破 |
| 100%（最も広げる） | | 96撃破 | 25撃破 | **71撃破** |

- **泡：狙いどおり。絞ると 2.2倍**
- **ミサイル：効いていない**（誤差の中）
- **迫撃砲：逆。広げたほうが強い**

**原因は分かっています。発射レートです。**
迫撃砲は **1.8秒に1発**しか撃たないので、砲弾どうしが時間的に重なりません。
重ならなければ密度は生まれず、代わりに「広く撒いたほうが道の敵に当たる確率が上がる」が勝ちます。
泡で効くのは、**拘束で敵がその場に溜まる**ため、あとから来た弾が重なるからです。

**試して駄目だったこと（どちらも実測）：**

| | 結果 |
|---|---|
| 1発を4発に割る（合計火力は据え置き） | 迫撃砲 58 → **30撃破**。勾配は平らのまま。**ただの弱体化** |
| レートを4倍・1発の威力を1/4（DPS据え置き） | 迫撃砲 19/41/43。**やはり逆のまま** |

### 伺いたいこと

**「幾何だけで成立させる」という縛りは、私が勝手に置いたものです。**
実測で2武器では成立しないと分かった以上、外していいか伺います。

| | 案 | 中身 |
|---|---|---|
| **A** | **倍率を入れる** | 「同じ火薬を、指定した面に配る」＝絞るほど1発が重い。他の武器の集弾率とまったく同じ規則になるので、ゲーム全体で1本の説明になる。**私の推しはこれです** |
| **B** | **役割を分ける** | 迫撃砲は「広く見る武器」、泡とミサイルは「絞る武器」。実測に一番忠実だが、**分類の中で規則が割れる** |
| **C** | 今のまま | 泡だけ効く。迫撃砲は広げるのが正解のまま残る |

A にすると、泡は幾何と倍率の両取りになって効きすぎます（2.2倍 × 約1.8倍）。
その場合は**泡の着弾円の幅を詰めて**釣り合わせます。A でよければ、そこまでやります。
