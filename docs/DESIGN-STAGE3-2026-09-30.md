## 2. 段3の骨格

1. **重ね取りの式を変える**（§3）：同じ軸は足してから掛ける。レートだけは上限に近づく式
2. **凸は「その札の主な1軸」だけに、天井つきで**（§4）
3. **遺物の上限を格で開かない**（§5）。格で開くのはアセンション（段4）に回す
4. **カードを作り直す**（§6）：死・同を整理し、レア度ごとの役割を決める
5. **前提のある上位札**（§7）：前提を2枚取ると3択に出る。**1枚だけ**。射程・範囲を広げる効果はここにだけ置く
6. **敵に耐性を持たせる**（§8）：装甲・耐火・耐寒・耐電・掴めない。**答えになる武器とカードを必ず置く**
7. **武器の作り直し**（§9）：レーザーライフル・ミサイル・触手（§12-1 のユーザー指定）
8. 測り方は親の設計書 §11（1種だけ・安い武器だけ・上手な混成）

**力の予算（親 §10）との関係**：第30章までで「その出撃のカード ×30・凸 ×5・遺物 ×10」の取り分を置いた。§1-1 の実測（カードと凸で ×1.3〜3.1・遺物 ×1.9〜3.0）は**予算より下**にある。
段3では、**取り分の天井を式で決め（§3〜§5）、実際の値は予算に向けて上げる方向**で置く（確定方針「プレイヤーを絞る方向で考えない」）。絞るのは天井の無い伸び方だけ。

## 3. 重ね取りの式（1出撃の中）

### 3-1 形（案）
| 軸 | いま | 案 |
|---|---|---|
| ダメージ | 1枚ずつ掛け算 | **足してから掛ける**：×(1 ＋ Σ増分)。1.32 を5枚 → ×2.60（いま ×4.01） |
| レート | 1枚ずつ掛け算 | **上限に近づく**：×(1 ＋ R × S/(S＋R))。S＝増分の合計、R＝天井（案 2.0＝最大 ×3） |
| 数（同時発射・跳弾・連鎖・貫通・掴む数） | 足し算 | そのまま（足し算） |
| 状態異常の持続 | 掛け算か足し算 | 足し算に統一 |
| **レジェンドの「さらに」** | — | レジェンドの一部は**別枠の掛け算**（×2 など）。「この1枚で激変」を残す |

- 例：冷却フィン（+25%）5枚は、いま ×3.05 → 案 ×1.77（S＝1.25・R＝2）。10凸で積むと、いま ×43 → 案 ×2.2（§4 の凸の天井 +150% を入れた値）
- 汎用の札（全武器の過給機など）も同じ軸に入る。**武器の札と汎用の札は同じ S に足す**
- ツリー（×2.2 など）と遺物は、カードの外の別の掛け算のまま（ツリーはコインの予算、遺物は §5 の予算）

### 3-2 なぜこの形か
- **足し算にまとめる**と、同じ軸を積むほど1枚の価値が下がる ＝ 別の軸・別の札を取る理由ができる（Path of Exile の increased・下調べ §2）
- **レートだけ天井**：レートは「見た目の忙しさ」「弾の数＝重さ」「足止めの掛け直し」に全部効く。ここだけは数字で頭を押さえる（ユーザー §14）
- 3択の札の説明は、**取ったら実際に何倍になるか**を出す（重ねたときの値）

### 3-3 気をつけること
- いまのカードの数値は「掛け算で重なる」前提で決めてある。足し算に変えると**同じ札でも弱くなる**ので、1枚あたりの数値は §6 で上げて置き直す（予算の ×30 に向けて）
- 測定器（`tools/sim.html`）は `Game.applyCard` を呼ぶので、本体を直せば測定も同じになる（写さない）

## 4. 凸（ダブり）

| | いま | 案 |
|---|---|---|
| 効く範囲 | 1枚の apply の中の全部の値（dmg・rate・count・貫通…） | **その札の主な1軸だけ**（札に `rankAxis` を書く） |
| 伸び方 | 0〜3凸 +5%/凸、4凸で +50%、以後 +50%/凸・**上限なし** | 0〜3凸 +5%/凸、4凸で +50%、以後 **+25%/凸**、**8凸（512枚）で +150% が天井** |
| 整数の軸 | 凸で本数も増える（rki） | 本数の札は凸で増やさない（連鎖・跳弾が凸で積み上がるのを止める）。代わりに主な軸を「本数以外」に置く |

- 第30章までに届く凸は、通しの配布で**4凸前後**（段3で実測して確かめる）。この範囲はいまとほぼ同じ
- **アセンションで凸をどこまで伸ばすかは段4**（ユーザーの答え6「全体を終えてから伸び幅を決める」）。8凸の天井は段4で上げてよい前提で置く
- パックの上振れ（運の良い引き）はご褒美として削らない（ユーザーの答え7）。天井は「上振れしても壊れない」ための置き場所

## 6. カードの作り直し

### 6-1 レア度ごとの役割（案）
| レア度 | 役割 | 量の目安（§3 の足し算で） |
|---|---|---|
| コモン | 1軸を伸ばす（ダメージ・レート・持続） | 増分 +30〜40% |
| レア | 2軸、または到達体数（貫通・連鎖・跳弾・数）+1〜2 | 増分 合計 +50% 相当 |
| エピック | **挙動を足す**（付与・分裂・残る場・連鎖の条件） | 数値より効果 |
| レジェンド | **遊び方を変える**（代償つきの「さらに」の掛け算・形の変化） | 別枠の掛け算 ×2 前後か、形の変化 |

- 「レア度が上なのに弱い」組（高圧ノズル・重装炸薬・燕返し・弾幕射撃）は、この表で作り直す
- 「下の札の数枚ぶん」のレジェンド（業火・千本桜・八腕・泡の海・永久凍土・弾幕射撃）は、**形の変化**へ差し替える

### 6-2 武器ごとの作り直し（案・1武器5〜6枚）
（作り直しの武器＝レーザー・ミサイル・触手は §9 で）

| 武器 | 残す | 差し替え・新しく |
|---|---|---|
| ガトリング | 給弾ベルト・冷却フィン・徹甲弾・加熱暴走・弾幕結界 | 多銃身 → **「曳光弾」**（当たった敵が数秒「装甲 −○%」）／暴発装薬 → **「掃射」**（首振りの速さ ×2・1体あたりの滞在が短い代わりに群れに強い） |
| 火炎放射器 | 高圧燃料・ナパーム・延焼 | 高圧ノズル → **「粘着燃料」**（燃えている敵が隣に燃え移る）／業火 → **「青い炎」**（燃焼が耐火を無視・レート ×0.7） |
| 毒ガス | 長期滞留・腐食・神経ガス | 濃縮ガス・猛毒 → **「重い霧」**（雲が通路に沿って流れる）と**「腐蝕の雲」**（雲の中の敵の装甲 −50%）。**雲の広さは §7 の上位札へ** |
| 凍結装置 | 深冷・砕氷 | 急速冷却＋氷結弾 → 1枚「急速冷却」に統合／永久凍土 → **「氷の棺」**（凍った敵が倒れると周りを凍らせる） |
| 刀 | 研磨・二刀・斬鉄・居合 | 燕返し → **「返し刃」**（斬った方向の逆へもう一度斬る） |
| 手裏剣 | 反射増加・毒手裏剣・三枚重ね | 薙ぎ払い → **「追尾刃」**（跳ねた先を一番HPの高い敵にする）／千本桜 → **「影分身」**（手裏剣が当たった所に、もう1枚が同じ軌道で追う） |
| 泡 | 連泡・酸泡・泡沫 | 大泡 → **「弾む泡」**（割れた泡が隣へ1回跳ねる）／泡の海 → **「泡の檻」**（閉じ込めた敵が受けるダメージ +○%） |
| 迫撃砲 | 大口径榴弾・速射砲座・絨毯爆撃 | 重装炸薬 → **「徹甲榴弾」**（装甲を無視する）／弾幕射撃 → **「焼夷弾」**（着弾の所が燃える） |
| テスラ | 5枚とも残す | 数値を §3 の足し算に合わせて置き直す |

### 6-3 汎用の札（案）
- 同じ軸の2枚（増設装甲と重装甲・金メッキ弾と戦利品・過給機と冷却系統・徹甲化と総力戦）は**1枚ずつにまとめる**
- 空いた枠に**耐性の答え**（§8）：「徹甲化」→「**装甲貫通**」（全武器の1発が装甲を ○% 無視）／「照準補正」→ 会心の無い4種には「状態異常の付与率」に読み替える形か、会心を全武器に持たせる
- 金メッキ弾・戦利品（コイン）は、コインが第30章で打ち切り（親 §2-5）なので**アセンションでは出さない**

### 6-4 連携の札
- 作り直す武器（スナイパー→レーザー・ミサイル・触手）の連携7枚は、武器と一緒に作り直す
- **泡＋毒ガス（毒泡）は重さの報告がある**（2026-09-28）。作り直すときに、残る雲の数に上限を置く
- 弾道共鳴の上限（+400%）は §3 の天井の外で効いているので、§3 のダメージの足し算に入れる

## 7. 前提のある上位札

### 7-1 仕組み（案）
- 札に `needs: ['札A', '札B']`（その出撃で両方取っていると3択に出る）と `maxStack: 1`
- 3択の抽選（`draft.js`）で、前提を満たしていない上位札は候補から外すだけ。**レア度はエピック扱い**（出る確率は 10%の枠の中）
- 上位札は**1武器あたり1〜2枚**。取れるのは1出撃に1枚（別の武器の上位札は別に取れる）
- 図鑑と確認室に「この札の先」を出す（Rogue Tower の道筋・下調べ §3）

### 7-2 射程・範囲を広げる札をここにだけ置く
ユーザー §14「これらを一枚しか取る事が出来ないようにするなどの制限を用いれば、私が最初に禁止した範囲や射程を広げるなどのスキルをプレイヤーに与えることが出来ます」

| 武器 | 上位札（案） | 前提 | 効果（1枚だけ） |
|---|---|---|---|
| 毒ガス | 広域散布 | 長期滞留＋腐食 | 雲の広さ +40%（いちばん効く軸・実測 76→130 で漏れ 71→19） |
| 迫撃砲 | 大口径化 | 大口径榴弾＋速射砲座 | 爆風の半径 +30% |
| 火炎放射器 | 長柄ノズル | 高圧燃料＋延焼 | 炎の届く距離 +30% |
| 刀 | 長巻 | 研磨＋居合 | 間合い +30% |
| 凍結装置 | 寒波 | 深冷＋砕氷 | 冷気の半径 +25% |
| テスラ | 送電塔 | 高圧コイル＋連鎖増幅 | 射程 +25%・連鎖の届く距離 +25% |
| ガトリング | 狙撃架台 | 給弾ベルト＋冷却フィン | 射程 +30%・首振り ×0.7 |

## 8. 敵の耐性

### 8-1 持たせる耐性（案）
| 耐性 | 中身 | 答え（武器） | 答え（カード） |
|---|---|---|---|
| **装甲**（いまの盾の兵を強める） | 1発ごとに引く（最低15%は通す・いまの式のまま）。量は雑魚HPの割合で | 1発が重い：刀・迫撃砲・レーザー | 装甲貫通（汎用）・曳光弾・腐蝕の雲・徹甲榴弾 |
| **耐火** | 燃えない・火のダメージ ×0.5 | 火以外 | 青い炎（耐火を無視） |
| **耐寒** | 凍らない・減速 ×0.5 | 凍結以外の足止め（泡・触手の壁） | — |
| **耐電** | 感電しない・連鎖がそこで止まる | テスラ以外 | — |
| **重量**（いまのボスと同じ） | 掴めない・押し戻せない・閉じ込められない | 火力 | — |

- いまある性質（速い・硬い・群れ・再生・分裂・入れ子）はそのまま。**再生は「燃えると止まる」＝火炎が答え**になっていて、この形の見本
- 耐性は**敵の種類に付ける**（BTD6・Kingdom Rush の形）。いまの8種に足すか、新しい種類を足す（§11 で決める）
- **無効は作らない**（Arknights の最低保証・Legion TD 2 の ±25%）。「効きにくい」までにして、詰みは作らない

### 8-2 章の特色として置く（案）
耐性の敵が**多く出る章**を D(n) と一緒に置き、**詰まる章の理由**にする（親 §2-1「詰まる章・楽になる章を意図して置く」）。

| 章の帯 | 多い耐性 | 問うこと |
|---|---|---|
| 第6〜9章 | 装甲（初めて） | 1発の重い武器を1つ入れる |
| 第11〜14章 | 耐火 | 火炎に頼り切らない（火炎を手に入れた直後の章） |
| 第16〜19章 | 耐寒 | 凍結以外の足止め（凍結を手に入れた直後の章） |
| 第21〜24章 | 装甲＋群れ | 重い武器と範囲の両方 |
| 第26〜29章 | 混ぜる | 全部 |
| ボスの章 | **ボスごとに1つ**（第15章 装甲・第20章 耐寒・第25章 耐火・第30章 重量＋装甲） | その周の理解度（ユーザーのボスの方針「DPS チェック」） |

- 武器をもらった直後の章で、その武器の苦手を出す（「もらった武器だけで勝つ」を止める＝§8 混成の原則）
- 値（装甲の割合・出る割合）は§1-3 の実測（最前線で1発が雑魚の数%〜十数%）から置き、**親 §11 の3つの型**（1種だけ・安い武器だけ・上手な混成）で確かめる

### 8-3 見た目
- 耐性は**色と形で一目で分かる**ように（装甲＝金属の縁・耐火＝青い縁・耐寒＝白い霜・耐電＝黄色の輪）。演出の方針（結果画面が基準）に沿って、確認室に並べて見せる
- 効かなかったとき（弾かれた・燃えなかった）に小さな表示を出す（いまの「バリアで弾かれた光」と同じ扱い）

## 9. 武器の作り直し

### 9-1 レーザーライフル（スナイパーの置き換え・親 §7 の答え4）
- 光線は**壁で2回反射**（カードで増やせる）。通った線の上の敵を**全部貫く**
- 太さは**いまの弾より少し太い**（ユーザー「視認性とかっこよさ、性能の底上げ」）
- コアと味方の武器には当たらない
- 撃つ向き：置いた向き（6方向の花）の射界の中で、**反射を含めた線がいちばん多くの敵を通る角度**を選ぶ（撃ちっぱなしの首振りのまま・狙う場所はプレイヤーが決めない＝設計の原則）
- 反射の計算：タイルの壁に対する光線の交差（六角の絵ではなくタイルの判定。経路探索と同じ層）
- コスト 3（いまと同じ）。スナイパーの札5枚と連携3枚は作り直す（反射 +1・太さ・当たった敵に印・貫くたびに威力が増える、など）
- **確かめること**：第25章で単独 1312（12種中11位）だった漏れが、中位に入るか

**【実装 0929zn】**撃つ向きは、ほかの武器と同じ首振りの向きのまま（狙う角度は選ばない）。反射は**六角の壁**で計算（タイルで計算すると絵の上で壁の中を通った）。

### 9-2 ミサイル

### 9-3 触手（親 §12-1 のユーザー指定）
