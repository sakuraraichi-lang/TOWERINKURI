合成武器企画書

ゲームの飽き防止、また、連携とは別に機能する武器のアップグレード要素として、設置中に隣り合わせで置いた武器が合成される、と言うシステムを用意します。
・A+B=Cのような感じで、基本的にCはAの札の影響を受ける、Aとして扱われる武器という感じです
・隣り合わせで合成が出来る時に合成ボタンが光ってAの武器の左上などに表示
・合成するとAの場所に合成後武器ができあがる
・これは上位パックから出るカードでの解禁要素です
・カードを所持している時だけ合成の選択肢が発生します。
・合成する際にコストを余分に2払います、合成後の方が強いのは当たり前ですが、ワンパターンゲームを減らす目的が大きいです。

例:刀+触手=異界の剣
合計コスト8
前方に横に広く縦に狭い長方形に近い範囲を担当する、目の前の広い範囲を切り裂いて空間を割き、中から触手が出てくる、挙動としては切り裂き（大ダメージ）+触手（中ダメージの持続攻撃）、置いた目の前だけだがかなり強い攻撃ができる。刀のピックスキルが乗るため斬撃が増える時に二重に斬ってる様に見えるように、斬撃と空間割きのエフェクトに少し傾きを持たせてください。

例:凍結装置+火炎放射器=相反の渦
合計コスト10
範囲は凍結装置から変わらず氷と炎が渦巻く、元の広い範囲に高火力だがコストが非常に重いのが難点。

例:ガトリング+手裏剣=スターアサルト
合計コスト4
元のガトリングと手裏剣よりも長く広い範囲を、やや大きめの星形弾で制圧する武器、貫通上限に達すると星形弾が弾けて範囲攻撃をする。

この様な感じで武器の組み合わせによって新たな武器を生み出し、より強くなってるが、コスト的にいっぱい置きたい時はどうするかなどを悩んでもらう。

## 本体の整理（2026-10-06・Opus）

- **A＋B＝C**。C は **A として扱う**（A の札が乗る・A の上限15基に数える、など）。合成すると A の場所に C ができ、B は消える
- 隣り合わせで合成できるとき、**合成ボタンが光って A の左上に出る**。押すと合成
- 解禁は**上位パックから出るカード**（アセンション専用の札）。**その札を持っているときだけ**合成の選択肢が出る
- **合成するとコストを余分に2払う**（例：刀＋触手＝異界の剣は合計コスト8）
- ねらい：強くなるのは当たり前。**ワンパターンを減らす**こと。コストの重さで「数を置くか、合成で強い1基か」を悩ませる
- 例の3つ：異界の剣（刀＋触手）・相反の渦（凍結＋火炎）・スターアサルト（ガトリング＋手裏剣）。異界の剣は**斬撃と空間割きの演出に少し傾き**（刀の札で斬撃が増えたとき二重に斬って見えるように）
- 隣の強め合い（1006f・レート）とは別の仕組み。合成した C の隣の数え方は C を A として数える案（着手時に確かめる）
