## 気になった点
1. **同じ版・同じシードで通しが再現しない**（上記）。段D・E との比較は、シード1〜12を複数回ずつ回した集計で見ること。A と B の差（到達 9/12 と 8/12、中央値 180.3 と 184.3 分）がこの揺れの目安。
2. 第30章 'timeout'（測定器の上限）が支配的。段D・E で第30章の本数が変わっても、これで測定上限に当たる出撃が増減するかを見ること。
3. 第20・25・29・30章の再挑戦の多さ。第20章は第1〜2ウェーブでの負けが多い（ボス以前）。
4. 氷の棺・泡の檻は第15章 D17 では測れない（床）。第25章 D22 で測るのが適切。
5. ガトリングは全札ありのほうが札なしよりはるかに良い（第25章 D22：4350 → 27）。札なしガトリングが弱いのではなく、全札の上積みが大きい。
