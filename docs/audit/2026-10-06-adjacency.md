## 問いに当てはめた数字（判定は書かない）
- **1種だけ：条件で変わらない。** 第25章の漏れ12本が4条件で1本ずつ一致（155,142,148,127,154,150,141,133,161,132,140,119）。第15章も全0。
- **「隣を狙う＋0.15」と「range＋0」の比（第25章・漏れの中央値）**：
  - cheap：23 対 41.5 ＝ adj＋0.15 のほうが **漏れが少ない（約0.55倍）**・clear 12/12 対 1/12。
  - mix：35 対 19.5 ＝ adj＋0.15 のほうが **漏れが多い（約1.8倍）**・clear 0/12 対 4/12。mix の adj 12本（24〜54）と range 12本（17〜29）は、最小値どうし（24 対 17）でも、範囲が重なるのは 24〜29 だけ。
  - mono：同じ。
- **0.15 そのものの効き（同じ置き方で 0 → 0.15）**：cheap・adj 23.5 → 23（clear 12/12 のまま）、mix・adj 34 → 35（0/12 のまま）。シードごとの漏れは （第25章・adj 置き・0 と 0.15 をシードごとに比べて）mix は 7本が増え・4本が減り・1本が同じ、cheap は 6本が増え・5本が減り・1本が同じ。**中央値の差（0.5〜1）は、同じ設定を測り直したときの振れ（CLAUDE.md に 75 と 104 の例）より小さい。**この測定では 0.15 だけでは、漏れの中央値は動いていない。
  - 見立て（未検証）：CLAUDE.md の「火力は漏れを動かさない（効くのは到達体数）」と同じ形。+15〜45% の火力は、第25章でも漏れの中央値としては見えない。**adj の効きは置き方（隣に固める＝覆いが変わる）の側にあり、倍率の側ではない。**倍率だけを見たいなら adj 置き同士の 0 と 0.15 の比較（上の行）で、差は出ていない。
- **range＋0 に対する帯**：cheap の adj は range より良い側に外れ、mix の adj は悪い側に外れる。どちらも mix 19.5〜35・cheap 23〜41.5 という、1種だけ（141.5）の約1/4〜1/7の帯の内側。**「同じ帯」と呼べるかは校長・ギャルの判定。**
