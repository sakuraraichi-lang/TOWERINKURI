# カードの棚卸し：死んでいる／ほぼ同じ／生きている — 段3の下調べ 2026-09-30

設計書 `docs/DESIGN-REBUILD-2026-09-29.md` §14「カードの作り直し」のための仕分け。
**クラウドのセッションで作った**（ローカルのセッションが週の上限で止まったため）。

**これは「コードを読んだ判定」で、実測ではない。**カードの `apply` が書き換える値と、その値を戦闘（`src/combat.js`・`src/weapons.js`・`src/state.js`）のどこが読むかを突き合わせた。
強さの順位は出していない（強さは漏れた数で測る決まり。段3の設計で、残す札を決めてから測る）。

**【2026-10-05 段3b のあと】9武器と汎用の札は作り直した**（ver 0929zs・パッチノートに札ごとの前 → 後）。この表の「死・半死・同」は作り直す前の判定。**表に無かった死んでいた札が3つ見つかった**（加熱暴走：熱が溜まらず札なしと同じ漏れ・砕氷と永久凍土：「凍った敵の被ダメージ +○%」が一度も効いていない・感電：札なしと同じ漏れ）。作り直した武器は札ごとの漏れの比を測り直した（パッチノート 0929zs）。作り直さなかった札（レーザー・ミサイル・触手・連携・上位札）の死んでいる札：締め上げ（触手・札なしと同じ 1.04）・弾道共鳴（ラン側の値を if の中で書いていて重ねても伸びない）

## 判定の決め方

| 判定 | 意味 |
|---|---|
| **死** | 効果が戦闘で読まれない・読まれても意味を持たない・同じ枠の別の札に完全に負けている（同じ軸・同じレア度以下で、数字だけ小さい） |
| **半死** | 効くが、説明文の仕組み（射界の広さ・範囲）はもう無く、実質「ただの○倍」。または効く武器が一部だけ |
| **同** | 別の札と**同じ軸を同じ形で**動かすだけ（数字とレア度が違うだけ）。統合か、片方を別の効果へ差し替える候補 |
| **生** | その札にしかない効果・挙動の変化がある |
| **（作り直し）** | 札そのものは生きているが、武器が作り直しの対象（スナイパー→レーザーライフル・ミサイルの抑制・触手 §12）なので、武器と一緒に作り直す |

**前提として押さえた事実（コード）**
- 射界は武器ごとの固定値（段1a）。「射界の広さで効く」札は `Game.arcT`（固定の幅が、旧可動幅のどこにあるか）で効くだけ（`state.js:843`）。ガトリング 0.34・手裏剣 0.42 から動かない
- **会心（crit）が効くのは**：弾（ガトリング・スナイパー・手裏剣）・テスラ・刀・指定攻撃（ミサイル・泡・迫撃砲）。**火炎（扇）・毒ガス（雲）・凍結（全周）・触手（掴み）には会心が無い**（`combat.js` の `coneDamage` を火炎は crit なしで呼ぶ・`pulse`・`grab`・雲の `damage` に crit が無い）
- **貫通（pierce）が効くのは弾だけ**：ガトリング・スナイパー・手裏剣（`combat.js:1421`）。ほかの9種には効かない
- **足止めの合計は1体8秒で打ち止め**（`BAL.ccMaxSec`）。掴む時間・閉じ込める時間を伸ばす札は、ここに当たると効かなくなる
- 範囲（key: size）と射程（key: range）の遺物は `OFF_CARD_KEYS` で**既に削除済み**（`cards.js:371`）。表には入れていない
- カードの重ね方は**全部が掛け算**（`w.s.rate *= Game.rk(…)`）。凸（ランク）は `Game.rk` で「1を超えるぶん」を伸ばす

## 段3の設計に持っていく点

1. **「レア度が上なのに弱い」札が4組ある**（高圧ノズル＜高圧燃料・重装炸薬＜大口径榴弾・燕返し≦居合・弾幕射撃＜絨毯爆撃）。3択で上のレア度が出たときの嬉しさを壊している
2. **レジェンドの半分が「下の札の数枚ぶん」**（業火・千本桜・八腕・泡の海・永久凍土・弾幕射撃）。§14「意味のある効果に差し替え」の本命
3. **汎用の札に「全武器に効く」と書いてあるのに効かない武器がある**（会心・貫通）。耐性（§14）を入れるなら、会心・貫通は「装甲への答え」として意味を持たせ直せる
4. **毒ガスの札は、効かない軸（ダメージ）に2枚、効く軸（雲の広さ）に0枚**。雲の広さは「前提のある1枚札」で出せる（ユーザー §14 の範囲・射程の解禁の形）
5. **足止めの時間を伸ばす札（4枚）は、8秒の打ち止めがあると天井で死ぬ**。止める時間ではなく「止めた敵に何が起きるか」の札に替える候補
6. レートの源（冷却フィン・過給機・冷却系統・律動の遺物3枚・ツリー ×2.2・加熱暴走）は全部掛け算。**重ね取りの式**（`docs/audit/2026-09-30-td-research.md` §2）とまとめて設計する
