### 2-2 arc の値が効く箇所（すべて）
1. **首振り**（`combat.js:938-954`）：`w.angle = face + sweepA`、`sweepA` は ±arc の間を `BAL.sweepSpeed`=1.15 rad/s（`balance.js:65`）で往復。周期 = 4·arc/1.15 秒。arc が広いほど1点に向く時間が反比例して減る。`def.sweep`（武器ごとの速度）は**どの武器も未定義**。
2. **集弾率 `groupingOf`**（`state.js:847-854`）= `1 − arcT × BAL.spreadPenalty(0.55)`（指定攻撃は常に1、`gat_loose` 装備時は固定 0.45）。発射のたびに `w.group` に入る（`combat.js:1270`）。使われ方：
   - 弾の武器（ガトリング・スナイパー・手裏剣）：角度に `±(1−group)×BAL.spreadRad(0.34)` のランダムずれ（`combat.js:604-605`）。
   - 即着の武器：**ダメージに group を掛ける**（`coneDamage` `combat.js:658`：火炎・刀／`pulse` `combat.js:703`：凍結／`chainLightning` `combat.js:746`：テスラ）。arc最大で最大 −45%。
   - 触手 `grab`（`combat.js:724-743`）・毒ガスの散布は group を使わない。
3. **指定攻撃の着弾円半径 `spotR`**（`state.js:863-868`）：`lo=max(spot[0], splash)`、`hi=max(lo+24, spot[1])`、`R = lo + (hi−lo)·arcT`。ミサイル 72〜150、泡 58〜120、迫撃 96〜170（px）。1発あたりのダメージには倍率が掛からない（円の面積で密度が決まる）。円の中心は円内の一様乱数（`combat.js:816-819`）。
4. `inArc`（`combat.js:871-876`）は arc を見る関数だが、**src・tools のどこからも呼ばれていない**（射撃判定は首振りの角度で決まる）。
5. カード：`gat_barrels`（arcT×+3〜 同時発射、`combat.js:795`）、`gat_loose`（集弾を最低固定＋arcT×最大+80%dmg、`combat.js:609`）、`shk_sweep`（arcT×+60%dmg）。**広げると得**にする3枚。
6. スキル・遺物に arc を触るものは無い。`Skill.applyTo` の `c.turn`（`skilltree.js:671`）は対応するノードが1つも無い。

### 2-3 武器ごとの実際の意味
| 武器 | arc（首振り）| 扇の当たり | group（集弾）|
|---|---|---|---|
| ガトリング/スナイパー/手裏剣 | ±arc を往復 | 砲身の線上で最も近い敵（`targetAhead` `combat.js:980`）に発射 | 散布に効く |
| テスラ | 同上 | 線上の敵から連鎖 | ダメージ×group |
| 火炎/刀 | ±arc を往復 | 扇の半角は `cone`（火炎0.42・刀1.5）で固定、arc は**首振りの振れ幅** | ダメージ×group |
| 凍結 | 往復するが `pulse` は**全周**（角度判定なし）| 射程内すべて | ダメージ×group（**arc を広げるほど下がるだけ**）|
| 触手/毒ガス | 往復（線上の敵を標的）| grab / 散布 | 無関係 |
| ミサイル/泡/迫撃 | 首振りなし（`aimUpdate` `combat.js:938-946`）| 円の半径にのみ使用 | 常に1 |

- 範囲（爆風・雲・扇・射程）は**すでにツリー・カード・遺物から外してある**：`OFF_KEYS=['range','size']`（`skilltree.js:362-380`）、`OFF_CARD_KEYS`（`cards.js:509-512`）、`Game.addPct` は何もしない（`state.js:532-534`）。可変なのは **arc と向きと着弾円の位置**だけ。

### 3-1 凸（ダブり）の式
- 凸数 t = floor(log2(枚数/4))+1（4枚未満は0）（`state.js:459-462`）。必要枚数 4,8,16,32,64,128… `totuNeed` `state.js:464`。
- 倍率ボーナス `totuBonus(t)`（`balance.js:910-914`）：t=1〜3 は 0.05·t、**t≥4 は 0.5+0.5·(t−4)（上限なし）**。`rankMul = 1+bonus`（`state.js:472-476`、`noRank` 札は1固定）。
  - 例：t=0→0 / 3→0.15 / 4→0.5 / 6→1.5 / 10→3.5 / 16→6.5。
- 効き方（`state.js:495-506`）：`rk(v)=1+(v−1)·rankMul`（v<1の代償は伸ばさない）、`rka(v)=v·rankMul`、`rki(v)`は端数繰越の整数。
- 武器カード(wc_)は基本dmgに `rankMul`（`state.js:1035`）。遺物は `pct = relicBaseMul(3) × (1+bonus)`、数で効くものは `1+t`（`relics.js:159-168`）。
- カードの適用は `Game.applyCard`（`state.js:548-554`）。ユニット1基ずつ、`applyMods`（`state.js:1023-1050`）のたびに引いた順に掛け直す。

## 4. 経済とスキルツリー（`src/skilltree.js`）

### 4-1 コイン収入（`combat.js:560-562`）

## 10. 歪みの候補（事実・数値付き）

1. **凸の倍率が上限なし・t≥4で+0.5/凸の線形**（`balance.js:910-914`）。1枚の効果が `1+(v−1)·(1+bonus)` なので、dmg・rate・count・連鎖・貫通など**複数の軸に同時に掛かり、積になる**。カードだけ（stack全部）のdmg×rate×count指数：ガトリング t0 ×131 → t10 ×9.9e5、刀 ×681 → ×1.4e7、迫撃 ×249 → ×2.25e6、ミサイル ×51 → ×7.97e4、スナイパー ×97 → ×2.78e5、手裏剣 ×7.9 → ×33.8、テスラ ×5.8 → ×202。
2. **武器ごとのカード効果の桁が大きく違う**（同じ t10 で刀 1.4e7、手裏剣 34）。手裏剣は dmg×0.88 が5枚積みで 6.86（13→6.9）に下がる代償を受け、凸で伸びない。
3. **Legacy は `enemyHpGrowth^5` に直結する 5.378倍/章、×8の余裕**（`relics.js:78-84`）。ch30で 1.2e22。敵の総量は章あたり ×6.4なので、章あたり約×1.19が Legacy に含まれない差になる（`lateEnemyMul` 1.10・湧き数 1.05・直線項）。
4. **章をまたぐ跳ね**：chapterMul ch4→8（2.0→3.8→3.4）の直後 ch9 で 1.0 に戻る（HP総量 前章比 ×17.1 → ×1.8）、ボス章のHP総量 前章比 ch15 ×32.1／ch20 ×23.8／ch25 ×16.6／ch30 ×14、口が増える ch8(2口)・ch12(3口)・ch19(4口)・ch26(6口)で湧き数が ×1.2/×1.17/×1.14/×1.25（ch26 前章比 ×3.1）。
5. **アセンションの壁 ×30 が5章ごと**：ch35 で HP総量 前章比 ×150、その次の章で ×0.33。ボス章と壁章が同じ章（bossHp 300 × 壁30 = 通常の敵の9,000倍）。
6. **アセンションのパック個数が 1.5^Lv（上限なし）**：Lv20 で 66,505個/Lv、Lv30 で 3,835,021個/Lv（累計 1.15e7）。同じ Lv の経験値要求は ×4/Lv、パックを引くループは個数ぶん回る（`ascension.js:65-70`）。
7. **アセンションのプレイヤー倍率 ×4/Lv と敵 ×6.4/章の差が章ごとに ×1.6**（壁章で一度に ×30）。差を埋めるのは上限なしの凸だけで、Lv30 で凸 t16・5枚積み ×1,020 に対し、ch60 の敵/プレイヤー比は 2.6e7（新規到達プレイヤー・カード追い上げ考慮前）。
8. **射界が3つの効き方を同時に持つ**：(a)首振りの滞在割合 1/arc、(b)集弾率 1−0.55·arcT（即着武器のダメージ−45%まで／弾武器の散布）、(c)指定攻撃の円径。どれも「絞るほど良い」向き。凍結（全周パルス）は arc を広げると下がるだけ。触手・毒ガスは group を使わない。`turn`（ツリー）・`def.sweep` は未使用。
