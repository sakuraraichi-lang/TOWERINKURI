## 2. 案

### 2-1. 入口

- 第30章を**初めて突破した時点で**、下のタブの「転生」が「**アセンション**」に変わり、第31章が開く
- **このとき恒久の土台（Legacy）を第30章に合わせる**（`legacyDeep = 30`）。
  合わせないと、最後の転生が第28章だった人は、第31章の敵に対して土台が約 ×6.2³ ≈ 240倍 足りない
- **それ以降は何も戻らない。**コイン・スキルツリー・章の突破・配置はそのまま

### 2-2. 第31章から先の章

- 章は無限に続く（第31章、第32章…）。**盤は全員同じ**（`BAL.mapSeed` と章の番号で決める）
- 盤の形：口6つの型（crown6・wall6・hexring・lad6）を章ごとに回し、種を章の番号でずらす
- ボスは今までどおり5章ごと（第35・40・45…章）
- 敵の強さは今の式をそのまま伸ばす（上の ×6.2 / 章）

### 2-3. アセンションの経験値（**露骨に制御する**）

**章 n（31以上）を初めて突破したときの経験値**

```
E(n) = 100 × r^(n − 31)          r = 4（案）
```

**レベル k → k+1 に要る経験値**

```
L(k) = 100 × q^k                  q = 4（案）
```

- r = q なら、**新しい章を1つ突破するごとに、ちょうど1レベル上がる**。レベル ≒ 到達章 − 30 になる
- q を r より少し大きくすると（例 q = 4.5）、深くなるほど「1章でレベル1」に届かなくなり、伸びが鈍る。**ここがバランスのつまみ**
- **同じ章をもう一度突破したとき**の経験値（稼ぎ）は 2-6 の未決

**稼ぎが効かない理由**：r = 4 なので、2章手前の章を回しても 1/16、3章手前なら 1/64 しか入らない。
**稼げるのは最前線の章だけ**で、それも下の「繰り返しの割合」で絞れる

### 2-4. アセンションレベルのバフ（恒久のステータス）

- **案：全武器の火力 × A^レベル**（A = 3 から始めて測る）
- 敵は約 ×6.2 / 章なので、**レベルのバフだけでは追いつかないようにする**（A < 6.2）。
  残りを**カードの凸**が埋める形にすると、方針の「凸が難易度の軸に加わる」になる
- A をどこに置くかは、**第31〜40章を通しで測って決める**（何章で止まるか・止まった章を何回で抜けるか）

### 2-5. パック（今までと比べものにならない量）

- **レベルが上がるたびにパック**：P(k) = 20 × 1.5^k 個（案）
  - Lv1 で 30個、Lv5 で 152個、Lv10 で 1,153個、Lv15 で 8,758個
  - 第30章までの全部で出るのは約230個（約700枚 ÷ 1パック3枚）なので、**Lv5 で1回ぶんの量が30章ぶんに並ぶ**
- 出る分野：全部の分野から（連携パック・遺物パックも含む）
- **凸の段は倍々（4・8・16・32…枚）なので、1枚の凸を1つ上げるのに要る量も倍々で増える。**
  パックの量を指数で増やすと、凸は**ほぼ一定の速さ**で上がり続ける（＝方針の「指数関数的に増えていく凸を現実的に行える」）
- **画面の手当てが要る**：何千個も1つずつ開けられないので、まとめて開ける（演出は省略して、上がった凸だけ見せる）

### 2-6. 敵側のアセンション（誘引）

- **第31章から、誘引1段ぶん（敵の量 +25%）を常時**（方針どおり）
- 誘引の効き方は今の `mods.spawn`（同じ湧く時間に +25% 詰め込む）をそのまま使う
- **2段目から先をどう上げるかは未決**（下の 3）

### 2-7. スキルツリー

- 何も変えない（第30章で取り切っている）。コインは余る
- 誘引の4つの節はツリーには戻さない（敵側のアセンションとして使う）

## 3. ユーザーに決めてほしいこと

1. **敵側のアセンション（誘引）の2段目から先**
   - (a) 第31章から先はずっと誘引1段のまま
   - (b) 一定の章ごとに1段ずつ上げる（例：第31章で1段、第41章で2段…）
   - (c) プレイヤーのアセンションレベルに連動して上げる（例：5レベルごとに1段）
2. **同じ章をもう一度突破したときの経験値**
   - (a) 0（初めての突破だけ）。詰まったら凸と配置で抜けるしかない
   - (b) 少しだけ（例：初回の 1/16）。16回回すと1レベル
   - (c) 初回と同じ
3. **第30章を突破したあと、転生は残すか**
   - (a) 残さない（アセンションに一本化。以後は何も戻らない）
   - (b) 残す（戻してやり直したい人のため）

## 3-3. 測った結果（2026-09-26・Node の測定器）

- **第31章の入口**：第30章を突破した時点で恒久の土台を第30章に合わせるので、レベル0でも漏れ0で突破（2本×2回）。1章およそ240秒（本編の約2倍）
- **敵の上乗せなし**（今の式のまま・2本）：第31〜45章を**全部1回目で突破**。レベル15・開けたパック約1万7千個・凸の中央値7。**詰まる章が無い**
- **第31章から先の敵HPを1章ごと ×2 上乗せ**（2本）：第37章で11回目に突破（手前を16回回して）、**第38章で止まる**（稼いでも抜けられない）
- **×4 上乗せ**（1本）：第34章が壁、第35章で止まる
- ＝ 毎章の上乗せでは「全く詰まらない」と「稼いでも抜けられない」の間が狭い。**節目の章だけに壁を置く形にした**（上の答え）

## 4. 進め方（案）

1. 上の 3 が決まったら、第31章から先の章（盤・敵）とアセンションの入口・経験値・レベル・パックを入れる
2. 測定器を第31章から先まで伸ばす（第30章突破のセーブから始め、第31〜40章を通しで回す）
3. A（レベルのバフ）・r / q（経験値カーブ）・P（パックの量）を、**大きく振ってから狭める**
4. 版を上げてパッチノートに書く
