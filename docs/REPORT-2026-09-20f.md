## 2. スキルツリーが1画面で完結するようになりました

**節をタップしたら、その場で強化できます。**

- 詳細と「使用可能なコイン／まとめて購入」を**パネルの下に貼り付け**た
- ツリー側は残りの高さで縦横にスクロール
- 詳細も **アイコン＋題名＋一行＋大きなボタン** に詰めた

**実測：** 節をタップした直後、パネルをスクロールせずに購入ボタンが画面内にあります
（`panelScrollTop: 0` のまま `buyVisibleWithoutScroll: true`）。

## 4. 射界を作り直しました

> **扇は「首振り扇風機」。その範囲をずっと撫で続けるもの。**
> だから全部の武器が同じ幅に広げられると、常に広げたほうが得になる。

そのとおりでした。**武器ごとに絞れる幅を変えました。**

| 武器 | 絞れる幅 | 狙い |
|---|---|---|
| **スナイパー** | **3°〜34°** | **ほぼ直線。**貫通で列を抜く |
| ミサイル | 9°〜48° | 誘導するので狭くていい |
| 迫撃砲 | 9°〜52° | 一点に撃ち込む |
| 泡 | 14°〜63° | 狙う |
| 手裏剣 | 17°〜80° | |
| 触手 | 23°〜92° | |
| ガトリング | 11°〜92° | どちらにも振れる標準 |
| テスラ | 34°〜126° | 連鎖。広く拾う |
| 刀 | 40°〜143° | |
| 毒ガス | 44°〜143° | 撒く |
| 凍結 | 46°〜138° | 周囲を止める |
| **火炎放射器** | **52°〜160°** | **絞れない。**広く焼くための武器 |

集弾率も「**その武器が絞れる幅の中でどれだけ絞れているか**」で出します。

### 実測：広げるのが常に得、ではなくなりました

**旧仕様（全武器 0.13〜0.90）**

| | 1周 | 試行 |
|---|---|---|
| 全部絞る | 20.6分 | 12 |
| **全部広げる** | **18.0分** | **10** |

→ **広げるほうが有利**。ご指摘のとおりでした。

**新仕様（武器ごと）**

| | 到達 | 1周 | 撃破/秒 |
|---|---|---|---|
| 全部絞る | **3/5** | 24.0分 | 4.0 |
| 全部広げる | 5/5 | 21.1分 | 9.4 |
| **武器ごとの初期値** | 5/5 | **18.0分** | **10.4** |

→ **どちらの極端も最適ではなくなりました。**

### スナイパーは絞ると10倍

1基を直線の通路にまっすぐ向けて比較しました。

| 扇 | 集弾 | 撃破 |
|---|---|---|
| **3°（最も絞る）** | 100% | **41体** |
| 19° | 73% | 9体 |
| 34°（最も広げる） | 45% | 4体 |

**狙いを合わせた人が報われる形**になりました。

## 5. 音を入れました

`src/audio.js` を作りました。**音源ファイルは持たず、その場で波形を作ります**
（ビルドの無いプロジェクトなので、バイナリを増やしたくないため）。

| | |
|---|---|
| 効果音 | 発射（**武器ごとに音が違う**）・撃破・漏れ・配置・タップ・ウェーブ開始／突破・突破／敗北・パック開封 |
| BGM | 8音をゆっくり回すだけ。**盤面の邪魔をしない音量**。ホームへ戻ると止まる |
| 入切 | 戦闘の操作列に **🔊** |

守っていること：

- **最初のタップまで音を作りません**（ブラウザが自動再生を止めるため）
- **同じ音を連射しません。** 実測で400ステップ中33回まで間引かれています
- 🔊 を切ると**本当に0回**になるのを実測

**まだ「軽く入れた」段階です。** 音が気に入らなければ、種類ごとに差し替えます。
