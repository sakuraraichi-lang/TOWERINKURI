遊べます → `https://towerinkuri.vercel.app/`

「更新されていない気がする」ときは、そこの文字とこのノートの見出しを見比べてください。

**書き方の決まり**

- 新しいものが上
- **プレイヤーから見て何が変わったか**を先に書く。実装の話は後ろ
- 数字を書くときは**実測値だけ**。「たぶん速くなった」は書かない
- 直した不具合は、**どう壊れていたか**も書く（同じ壊れ方を繰り返さないため）

## ver 0921g

### 章が進んでも敵が増えなくなっていました

1ウェーブに出る敵の数に **260 という上限**がかかっていました。
第7章あたりでここに張り付いて、**そこから先はいくら進んでも敵の数が変わりません**でした。

敵誘引を買って「敵を増やしてコインを稼ぐ」をしても、**増えたぶんが切り捨てられていた**
ということでもあります。

- **上限を 900 に開けました。** これは処理が重くならない限界の値で、
  バランスを取るための数字ではありません
- **敵の数そのものにも伸びを付けました。** 1ウェーブごとに ×1.04（1章で ×1.22）

実測（2シードずつ・第1〜14章）で、1ウェーブに出る敵の数はこう変わります。

| | 第1章 | 第5章 | 第7章 | 第10章 |
|---|---|---|---|---|
| 前 | 26 | 146 | **260（上限）** | **260（上限）** |
| 後 | 30 | 420 | 900 | 900 |

**終盤の手応えが戻りました。** 湧き終わってから片付け終わるまでの時間が、
第11〜14章で **13〜16秒 → 51〜65秒**。同時に出ている敵は最大252体、
1フレームの処理は 0.36ms（予算16.7msに対して余裕があります）。

### 敵が黙って消えていました

盤面の敵が上限（900体）に達しているとき、**そのぶんの敵が湧かずに、
しかも「湧いた」ことにされていました。** 詰まっているときほど敵が減る、
という逆の挙動です。上限に当たっているあいだは湧きを待つように直しました。

## ver 0921f

### 章スキップに「鍵」が要るようになりました

これまでは、**第1章を完璧クリアしただけで、2周目からその章を飛ばせました。**
転生のたびに前半がほぼ全部飛ぶので、手を動かす場面がほとんど残っていませんでした。

**第13章の報酬「踏破の記録」を手に入れるまで、1章も飛ばせません。**

鍵を手に入れたあとの条件はこれまでと同じです。

| | 飛ばせる条件 |
|---|---|
| 完璧クリア（1体も通さず突破）した章 | 鍵があれば飛ばせる |
| そうでない章 | 鍵＋転生1回＋その章を通算3回突破 |

飛ばしたときに入るコインは、**前に自分で突破したときの最高額**そのままです。減りません。
同じ章を繰り返し飛ばして稼ぐことはできません（1周につき1回だけ）。

「踏破の記録」は**3択にもパックにも出ません。** 第13章を突破することでしか手に入りません。

## ver 0921b

### ランクを上げても何も起きないカードが11枚ありました

0921a でダブりをランクアップに回しましたが、**全59枚のうち11枚は、
ランクを上げても数字がまったく動いていませんでした。**
3択の札には「×1.12」と出るのに、実際には何も変わらない状態でした。

原因は2つです。

**① 数字を「いくつ以上にする」形で書いていたカード（9枚）**

感電・執行・毒手裏剣・神経ガス・酸泡・電磁爆縮・感電泡・雷神・無限刃。
「3秒以上にする」という書き方なので、ランクを掛ける場所がありませんでした。

| カード | 1枚 | 6枚 |
|---|---|---|
| 感電（感電の持続） | 3.5秒 | 5.6秒 |
| 執行（即死のしきい値） | 18% | 28.8% |
| 毒手裏剣（毒／持続） | 0.35／3秒 | 0.56／4.8秒 |
| 神経ガス（減速／被ダメージ） | +35%／+25% | +65%／+52% |
| 酸泡（酸だまりの広さ／持続） | 60／3.5秒 | 96／5.6秒 |
| 雷神（落雷の間隔） | 5秒ごと | 3.1秒ごと |
| 無限刃（1撃ごとの伸び／上限） | +6%／2倍 | +9.6%／3.2倍 |
| 弾道共鳴（1発ごと／上限） | +0.6%／+400% | +0.96%／+640% |

**② 個数を足すカードが、丸めで消えていた（5枚）**

三枚重ね・反射増加・多弾頭・絨毯爆撃・連鎖増幅。
1枚ずつ丸めると 1×1.12 が毎回1に戻るので、何枚重ねても増えませんでした。
**端数を次の1枚に繰り越す**ようにしました。

| カード（上限まで重ねたとき） | 手持ち1枚 | 手持ち2枚 | 手持ち6枚 |
|---|---|---|---|
| 三枚重ね（同時投擲） | +10 | +11 | +16 |
| 反射増加（跳ね返り） | +9 | +10 | +14 |
| 多弾頭（同時発射） | +6 | +7 | +10 |
| 連鎖増幅（連鎖数） | +10 | +11 | +16 |

### ランクで強くならないカードには、倍率を出さなくなりました

**加熱暴走**（上限そのものを触るカード。上限を動かすと「置いておくだけで
加速し続ける」に戻ってしまう）と**兜割り**（「必ず会心になる」なので伸ばす数字が無い）は、
何枚持っていても効果が変わりません。この2枚だけ、3択の札に倍率を出しません。

実測：59枚中、ランク6で効果が変わらないのはこの2枚だけになりました（修正前は13枚）。

### ダブったカードが「ランクアップ」になりました

これまでは、**同じカードをたくさん持っているほど、そのカードが出やすくなる**だけでした。
持っていても持っていなくても効果は同じだったので、被りが嬉しくありませんでした。

- **出やすさは所持枚数で変わりません。** レア度ごとの確率は固定です
- **ダブった分はランクになります。** 1枚増えるごとに、そのカードの効果が **+12%**

| 手持ち | 効果 |
|---|---|
| 1枚 | ×1.00（そのまま） |
| 2枚 | ×1.12 |
| 5枚 | ×1.48 |

実測（増設装甲・ライフ +6 のカード）：1枚で +6、2枚で +6.7、3枚で +7.4、6枚で +9.6。

**代償は一緒に大きくなりません。** たとえば弾頭肥大の「連射 ×0.55」は、
ランクを上げても ×0.55 のままです。ランクアップは強くなるためのものなので、
ダブるほど弱くなる部分があると意味が逆になります。

**銃身の数や貫通のような「個数で数えるもの」は丸めます。**
4本に12%を掛けると4.48本になり、数える側が切り捨てて**何も起きない**からです。
数ランクごとに1本増える形にしました。

### 射程が伸びると60fpsを割っていました

**敵が1〜2体しかいないのに、1フレームに 23.7ms** かかっていました（60fpsの予算は16.7ms）。

犯人は弾でも敵でも押し合いでもありませんでした。

| 切り分け | 結果 |
|---|---|
| 押し合いを切る | 23.66 → 23.41ms（0.25msしか使っていない） |
| 弾を全部消す | 23.47 → 23.90ms（むしろ無関係） |

調べる範囲が**射程の2乗**で増えるので、射程1058pxの武器が毎フレーム914区画を走査していました。

砲身の**線に沿って**探すように直しました。調べる量が射程に比例するだけになります。

| | 前 | 後 |
|---|---|---|
| 1フレーム | 23.66ms | **0.03ms** |

## ver 0920x

### 転生で残る強さが、到達した深さに追いつくようになりました

これまで**転生しても、既に抜けた章がちっとも楽になりませんでした。**
「転生で残る層」は遺物カードだけが担っていて、その力が到達点にまったく届いていなかったためです。

実測すると、必要な強さの **0.0017% 〜 0.0000085%** しかありませんでした。

効果量を上げて解こうとしましたが、**ほんの少し動かすだけで「全然足りない」と
「10⁸倍に発散する」の間を飛びます。** 90枚前後のカードの累乗なので当然でした。

そこで**役割を分けました。**

| | 役割 |
|---|---|
| **土台** | **桁を作る。** 到達した深さから自動で決まる |
| **遺物カード** | **色付け。** どのビルドに寄せるかを変える |

結果、**どの周でも土台が必要ぴったり**になり、遺物の上乗せは ×13〜19.6 で頭打ちします。
引きが悪くても既に抜けた章は必ず楽になり、引きが良ければその周がさらに楽になります。

### 遺物の累乗をやめました

同じ遺物を集めるほど累乗で伸びる仕組みを廃止し、**種類ごとに上限のある加算**にしました。
上限が無いと、9周ぶん集めたときに ×480 まで伸びていました。

ダメージ +100〜300% ／ 発射レート +50〜80% ／ コイン +100〜200%（種類ごと）。

### 転生でもらえる遺物パックを増やしました

以前は6章突破しても7パック（21枚）でした。土台が必要とする量から逆算して、
**初回転生で33パック、以降は20パック前後**にしています。

### 転生の回数と章の割り振りを直しました

前は終盤の2周が2章・1章しか進まず、**恒久成長だけで足りてしまって自力で登る意味がありませんでした。**

**6/9/12/15/18/21/24/27/30 に変更**（第1周が6章、以降は毎周3章ちょうど、転生8回）。
どの周も「自力で積む必要 ×5.67 ／ 積める ×28 ／ 余裕 ×5」で揃います。

## ver 0920w

### 30章になりました

5ステージだった本編を **30章**に増やしました。マップは生成しています。

- **型は章ごとに固定**（一本道 → 分岐 → 螺旋・島 → 三叉 → 広間 → 混成）
- **乱数の種は章番号**。何周目でも同じマップです
- 生成したものは全部検査に通しています（経路の長さ・置ける地面の数・十字砲火が組めるか）。
  **30章すべて合格**（地面157〜225 / 十字砲火155〜190 / 経路長20〜48）

新しい武器は**平均3章に1つ**出ます。
スナイパー2章／ミサイル5章／テスラ8章／火炎放射器11章／毒ガス14章／凍結17章／迫撃砲20章。

### 敵の強さの伸び方を引き直しました

| | 前 | 後 |
|---|---|---|
| 1ウェーブごと | ×1.30 | **×1.25** |
| 章ごとの追加 | ×1.35 | **廃止** |
| 1章あたり | ×5.01 | **×3.05** |
| 30章の合計 | （5章前提） | **×1.1×10¹⁴** |

### 敵の数と、湧き方

敵の数は **150ウェーブを通して 20体 → 200体の直線**にしました。
数は処理落ちと画面の見やすさに直結するので、指数では増やしません。

湧き方の式も変えました。前は「間隔 × 減衰」で持っていたのですが、
**これは敵の数と噛み合いません。** 数が増えると湧き時間が勝手に伸び、
数の少ない序盤は逆に一気に湧いて処理しきれませんでした
（第1章が「21体が1.3秒で全部湧く」状態で、漏れがちょうどライフぶん溜まって毎回死にました）。

**「湧き終わるまでの秒数」で持つようにしました（14秒）。**
敵が何体いても、ウェーブの前半は必ずこの長さです。

## ver 0920v

### 敵がどっと来るようになりました

ウェーブの**67%が「敵が湧くのを待っているだけ」の時間**でした。
ひどいところでは「湧き35.1秒 / 倒すの8.7秒」で、8割が待ち時間です。

湧きを詰めて、空いた時間を**敵の数**に振り替えました。

| | 前 | 後 |
|---|---|---|
| ウェーブの長さ | 30.7秒 | **23.4秒** |
| うち待ち時間 | **67%** | **50%** |
| 1秒あたりの撃破 | 9.4体 | **17.1体** |
| 1ウェーブの敵の数 | — | **約2倍** |

**敵の数を2倍にしても、ウェーブは3秒しか伸びず、難しさも変わりません**（測定器で5ステージ通し、どちらも5/5突破・試行回数も同じ）。
待っていた時間が、そのまま戦闘に変わっています。

処理の重さも見ています。同時に敵182体で、1フレーム平均 0.43ms（60fpsに対して39倍の余裕）。

### パックが「転生で開くもの」になりました

これまで**遺物パックが最初から開いていました。**
遺物は転生でしか手に入らない永続強化なのに、転生を知る前に触れてしまう状態で、
長い時間をかけて集めるはずのものを序盤で食い切っていました。

解放の条件を、ステージ数から**転生した回数**に移しました。

| パック | 前 | 後 |
|---|---|---|
| 基本 | 最初から1個持っている | **2ステージ突破** |
| **遺物** | **最初から** | **初めて転生したとき** |

## ver 0920t

### 転生2回でゲームが壊れる件を直しました

## ver 0920s

### 武器の見た目を作りました

12種が「色の違う丸＋棒」だったのをやめ、**形で見分けられる**ようにしました。
六角の台座＋武器ごとの砲塔で、撃った瞬間に砲身が後退します。
3文字の略号は準備フェーズだけ出して、戦闘中は形だけで読ませます。

### 設置枠はお金で前借りできなくなりました

設置枠は他の強化と性質が違って、**火力もカバー範囲も漏れにくさも同時に増え、
しかも全部と掛け算**になります。それが2〜3ステージ目に全部買い切れていました。

**踏破したステージ数ぶんしか伸ばせません。**
実測で、この縛りだけなら難しさはほとんど変わりません（5/5突破・21.1分）。

### 武器ごとに置ける数を見直しました

1基あたりの価値を実測してから振り直しました（撃破数は敵の供給数で頭打ちになるので、
「漏れをどれだけ止めたか」で測っています）。

1基だけで止めた割合：刀98% / 火炎89% / 毒ガス60% / 泡56% / 迫撃砲42% /
手裏剣32% / ガトリング21% / スナイパー21% / テスラ11% / ミサイル5% / 触手4% / 凍結3%

### コインの増え方

「集金効率」が累乗かつ上限なしで、実測で **Lv39・×153倍**まで伸びていました。
1ステージの稼ぎが ×25.7 / ×6.4 / ×38.1 と暴れていた原因です。加算に変えました。

### 湧き口に置くのが正解、ではなくなりました

指定攻撃に射線を持たせなかったので、**敵が必ず・常に・最大密度でいる湧き口**が

火力・射程・レート・範囲の上限を外し、値段で止める形にしました（上限つきは13個に）。

## ver 0920r

### 換装が何なのか分かるようになりました

「何と何を入れ替えるのか」「選ばなかったらどこで変えるのか」が伝わらない状態でした。

  元の効き方にも戻せます

- 「選ばなかったらどうなるか」をその場に書きました

### 射界を広げるのが得になるカード

広げるのは集弾率が落ちるだけの一方通行でした。広さ自体を利益に変える道を足しています。

| | |
|---|---|
| **多銃身** | 射界を広げているほど同時発射が増える（最大+3） |
| **暴発装薬** | 集弾率が最低で固定される代わりに、広げているほどダメージ（最大 ×1.8） |
| **薙ぎ払い** | 手裏剣。射界を広げているほどダメージ（最大 ×1.6） |

## ver 0920q ＋ 指定攻撃の作り直し

### 指定攻撃が「円に降らせる」ものになりました

ミサイル・迫撃砲・泡の3つを作り直しました。

```
盤面に円を置く → その円の中のランダムな点へ砲弾が降る
```

- **着弾まで当たり判定がありません。** 敵も壁も素通りします
- だから**射線を持たず、スナイパーやガトリングが欲しい地面を譲れます**
- 角度の縛りを撤廃。制約は射程だけで、壁の向こうにも置けます
- 射界のつまみが、そのまま**着弾円の大きさ**になります

ミサイルを「長射程」から「指定攻撃」へ移しました。
