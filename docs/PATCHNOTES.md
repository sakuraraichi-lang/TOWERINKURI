# INKURIMENT パッチノート

遊べます → `https://towerinkuri.vercel.app/`

版は**ホーム画面の右上**（`ver 0920v` のように出ます）。
「更新されていない気がする」ときは、そこの文字とこのノートの見出しを見比べてください。

**書き方の決まり**

- 新しいものが上
- **プレイヤーから見て何が変わったか**を先に書く。実装の話は後ろ
- 数字を書くときは**実測値だけ**。「たぶん速くなった」は書かない
- 直した不具合は、**どう壊れていたか**も書く（同じ壊れ方を繰り返さないため）

### 手裏剣を大量に撃っても重くならないようにしました

4枚刃にした直後、**851発で 16.5ms** 掛かっていました。1フレームの予算が 16.7ms なので、
手裏剣を並べた編成だけが露骨に重くなります。

**1発ずつ回転・塗り・縁取りしていたのをやめ**、回転角は全発で同じなので1回だけ計算し、
**120発ずつまとめて塗る**ようにしました。

| 発数 | 直した後 |
|---|---|
| 100発 | 0.11ms |
| 200発 | 0.22ms |
| 400発 | 0.46ms |
| **851発** | **1.06ms**（16.5ms から） |

1本の巨大な図形にまとめると、逆に塗りの費用が跳ね上がります（851発で 5.75ms）。
**区切って塗るところまでが直しです。**

## ver 0922o

### 武器ごとに、置くのに要るマスが変わりました

これまでは**どの武器も1マス**でした。ガトリングも迫撃砲も、置くときの重さは同じです。
強い武器ほど置き場所に癖が出るようにしました。

| 要るマス | 武器 |
|---|---|
| **1マス** | ガトリング・テスラコイル・凍結装置 |
| **横に2マス** | スナイパー・ミサイル・火炎放射器・毒ガス散布機・手裏剣 |
| **縦に2マス** | 触手・刀・泡・迫撃砲 |

**回転はしません。**向きは固定です。横2と縦2は同じ地面でも置ける場所が違うので、
「強い武器を持ってきたのに、ここには入らない」が起きます。

**置ける基数そのものは変わりません。**変わるのは置ける場所だけです。
3シードの通しで、30章までが 7〜8周・123〜141分。導入前（7〜8周）と同じ周回数です。

**2×2 は採りませんでした。**通路を六角で焼いているので地面は四角くまとまっておらず、
2×2 を要る武器は置ける場所がほとんど無く、通しが `2→5→9→4→4→4` に崩れました（3シードとも）。

### 触手・凍結・迫撃砲の絵を、やっていることに合わせました

| 武器 | これまで | いま |
|---|---|---|
| **触手** | ただの線が伸びるだけ | **根元が太く先が細い、うねる腕。**吸盤が付き、先は敵に巻き付く |
| **凍結装置** | 薄い輪が1本広がるだけ | **霜の波。**六条の結晶が外へ散り、内側に冷たい膜が張る |
| **凍った敵** | 色が青くなるだけ | **氷の棘が4本生える** |
| **迫撃砲・泡** | 平らな丸が滑っていくだけ | **地面に影を残して山なりに飛ぶ。**高いほど大きく見える |

迫撃砲は「降らせる」武器なのに、弾が地を這っているのと区別が付きませんでした。

## ver 0922f

### 置ける数を大幅に減らしました（上限52基 → 11基）

「置けすぎ」という指摘をいただきました。調べたところ、**上限まで取ると52基**でした。

原因は、**枠が「武器の種類ごと」だったこと**です。編成は4種なので、
スキルを1段取ると盤の上では +4 になります。種類ごとの数字をいくら刻んでも4倍されます。

**盤全体の総数で持つようにしました。** 6基から始まり、「増設基盤」を取るごとに +1、
最大11基です。1段あけるのに約5章かかる値段にしてあります。
種類ごとの上限は「1種類で盤を埋めさせない」ためだけに残しました。

第1章のガトリング4基は変わりません。

### マップを広くしました（15×21 → 21×27・面積1.8倍）

「仮に20基置けるなら広大なマップを用意するなり」という話を受けて、盤を広げました。
**出現口が増えたのはこの副産物です。** これまで口を2つ3つ開けると通路が交差して
近道ができ、ほとんど1つに偏っていました（終盤で 72%/21%/7%）。
盤が広いと口を離せるので、**終盤は 27%/35%/38% とばらけます。**

画面に入りきらないぶんは、指で見渡せます（小地図が出ます）。

### 転生しても、踏んだ章の地形は変わりません

転生のたびに30章ぶん作り直していたのですが、**それだと周が後退します**
（26章まで行った次の周が22章、20章の次が16章）。
かといって全部固定にすると、**苦手な地形に当たったとき永久に詰みます**
（第14章で3周ぶん足踏みしました）。

**踏んだ章はそのまま、まだ届いていない章だけ引き直す**形にしました。
積み上げたものは返ってきますし、壁に当たっても次の周で別の地形を引けます。

### 進み方

置ける数を減らしたぶん、**土台の余裕を 2 → 8 に上げて**埋め合わせました
（減らしただけだと9周かけても20〜24章で止まりました）。

3シードで `3→4→4→8→12→15→16→19→16→22`（159分）／
`3→4→7→10→14→18→15→22→25→30`（142分）／
`2→5→9→13→10→17→22→27→25→30`（123分）。

**30章まで9〜10周。**以前（20基あった頃）より明確に手応えがあります。

カードを選んだあと、**そのまま次のウェーブが始まります。**

### ダブったカードが「ランクアップ」になりました

これまでは、**同じカードをたくさん持っているほど、そのカードが出やすくなる**だけでした。
持っていても持っていなくても効果は同じだったので、被りが嬉しくありませんでした。

- **出やすさは所持枚数で変わりません。** レア度ごとの確率は固定です
- **ダブった分はランクになります。** 1枚増えるごとに、そのカードの効果が **+12%**

| 手持ち | 効果 |
|---|---|
| 1枚 | ×1.00（そのまま） |
| 2枚 | ×1.12 |
| 5枚 | ×1.48 |

実測（増設装甲・ライフ +6 のカード）：1枚で +6、2枚で +6.7、3枚で +7.4、6枚で +9.6。

**代償は一緒に大きくなりません。** たとえば弾頭肥大の「連射 ×0.55」は、
ランクを上げても ×0.55 のままです。ランクアップは強くなるためのものなので、
ダブるほど弱くなる部分があると意味が逆になります。

**銃身の数や貫通のような「個数で数えるもの」は丸めます。**
4本に12%を掛けると4.48本になり、数える側が切り捨てて**何も起きない**からです。
数ランクごとに1本増える形にしました。

| | 前 | 後 |
|---|---|---|
| 1フレーム | 23.66ms | **0.03ms** |

## ver 0920x

### 転生で残る強さが、到達した深さに追いつくようになりました

これまで**転生しても、既に抜けた章がちっとも楽になりませんでした。**
「転生で残る層」は遺物カードだけが担っていて、その力が到達点にまったく届いていなかったためです。

効果量を上げて解こうとしましたが、**ほんの少し動かすだけで「全然足りない」と
「10⁸倍に発散する」の間を飛びます。** 90枚前後のカードの累乗なので当然でした。

そこで**役割を分けました。**

| | 役割 |
|---|---|
| **土台** | **桁を作る。** 到達した深さから自動で決まる |
| **遺物カード** | **色付け。** どのビルドに寄せるかを変える |

結果、**どの周でも土台が必要ぴったり**になり、遺物の上乗せは ×13〜19.6 で頭打ちします。
引きが悪くても既に抜けた章は必ず楽になり、引きが良ければその周がさらに楽になります。

### 遺物の累乗をやめました

同じ遺物を集めるほど累乗で伸びる仕組みを廃止し、**種類ごとに上限のある加算**にしました。
上限が無いと、9周ぶん集めたときに ×480 まで伸びていました。

ダメージ +100〜300% ／ 発射レート +50〜80% ／ コイン +100〜200%（種類ごと）。

以前は6章突破しても7パック（21枚）でした。土台が必要とする量から逆算して、

**6/9/12/15/18/21/24/27/30 に変更**（第1周が6章、以降は毎周3章ちょうど、転生8回）。

## ver 0920w

### 30章になりました

5ステージだった本編を **30章**に増やしました。マップは生成しています。

- **型は章ごとに固定**（一本道 → 分岐 → 螺旋・島 → 三叉 → 広間 → 混成）
- **乱数の種は章番号**。何周目でも同じマップです
- 生成したものは全部検査に通しています（経路の長さ・置ける地面の数・十字砲火が組めるか）。
  **30章すべて合格**（地面157〜225 / 十字砲火155〜190 / 経路長20〜48）

新しい武器は**平均3章に1つ**出ます。
スナイパー2章／ミサイル5章／テスラ8章／火炎放射器11章／毒ガス14章／凍結17章／迫撃砲20章。

### 敵の強さの伸び方を引き直しました

| | 前 | 後 |
|---|---|---|
| 1ウェーブごと | ×1.30 | **×1.25** |
| 章ごとの追加 | ×1.35 | **廃止** |
| 1章あたり | ×5.01 | **×3.05** |
| 30章の合計 | （5章前提） | **×1.1×10¹⁴** |

前の伸び方は5章なら成立しますが、30章に伸ばすと ×10²⁰ になって急すぎます。

### 敵の数と、湧き方

敵の数は **150ウェーブを通して 20体 → 200体の直線**にしました。
数は処理落ちと画面の見やすさに直結するので、指数では増やしません。

湧き方の式も変えました。前は「間隔 × 減衰」で持っていたのですが、
**これは敵の数と噛み合いません。** 数が増えると湧き時間が勝手に伸び、
数の少ない序盤は逆に一気に湧いて処理しきれませんでした
（第1章が「21体が1.3秒で全部湧く」状態で、漏れがちょうどライフぶん溜まって毎回死にました）。

**「湧き終わるまでの秒数」で持つようにしました（14秒）。**
敵が何体いても、ウェーブの前半は必ずこの長さです。

## ver 0920q ＋ 指定攻撃の作り直し

### 指定攻撃が「円に降らせる」ものになりました

ミサイル・迫撃砲・泡の3つを作り直しました。

```
盤面に円を置く → その円の中のランダムな点へ砲弾が降る
```

- **着弾まで当たり判定がありません。** 敵も壁も素通りします
- だから**射線を持たず、スナイパーやガトリングが欲しい地面を譲れます**
- 角度の縛りを撤廃。制約は射程だけで、壁の向こうにも置けます
- 射界のつまみが、そのまま**着弾円の大きさ**になります

ミサイルを「長射程」から「指定攻撃」へ移しました。
