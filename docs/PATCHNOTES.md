## ver 0926a

### 浅い転生の繰り返しで稼げないように（経済の作り直し・その1）

プレイヤーの感想：
> 「転生前提ゲームで2章転生を繰り返し続けると後ろの章がクリアできるのが刺さらん」
> 「10章クリアする時間と2章転生をする時間に対する報酬があまりにもちぐはぐ」
> 「×どんどん強くなっていくタワーディフェンスゲーム ○『放置で1章2章クリアという広告』を見てパックを剥くゲーム」

**どう壊れていたか**（式を読んで確かめた）：

- **遺物の上限・パックの種類の解放・自動化の解放・転生10回のミッションが、「転生した回数」で開いていた。**
  回数は第2章で転生しても1増えるので、浅い転生を繰り返すだけで上限と解放を買えた
- **転生の報酬に固定分があった。**遺物パックは「3＋突破×0.25」、カードパックは最低1個。第2章で転生しても遺物4個・カード1個が出た。
  測定器で数えると、第1〜2章だけで転生する周は約4分で遺物4個、ちゃんと進める2周目は17〜19分で5個（時間あたり3倍以上）
- 恒久の土台（Legacy）はいちばん深く行った章が基準なので、浅く転生しても何も失わなかった

**直したこと：**

- **「転生の格」**を入れました。格は**転生したときの到達章**で決まります（4章ごとに1つ・転生していれば最低1）。
  遺物の上限・パックの種類の解放・自動化の解放は、回数ではなく格で開きます。浅いところで何回転生しても格は上がりません
  （ふつうに進めている周では、格は転生回数とほぼ同じ速さで上がります：到達 3・7・11・16・20・24・28章 → 格 1〜7）
- **前回の到達より浅い転生は、報酬が減ります。**掛け率 ＝（今回の突破 ÷ 前回の到達章）^3。
  前回20章まで行った人が第2章で転生すると0個、壁で9割まで行けた周なら7割ほど。**前回の到達まで進んだ周は今までどおり満額**です

| 敵 | 1〜2体しかいない |

**武器が「射程の円の中にいる敵を全部調べて」から、砲身の線に掛かるものを選んでいた**のが原因です。
調べる範囲が**射程の2乗**で増えるので、射程1058pxの武器が毎フレーム914区画を走査していました。

砲身の**線に沿って**探すように直しました。調べる量が射程に比例するだけになります。

| | 前 | 後 |
|---|---|---|
| 1フレーム | 23.66ms | **0.03ms** |

### 転生が効くようになったことを確認しました

0920x で恒久層を作り変えましたが、**式を合わせただけで実際に遊べるかを測っていませんでした。**
測ったところ、転生しても1章も進まないように見えました。
調べると負けていたのではなく、上の性能問題で測定が打ち切られていただけでした。

直したあとの実測：初回転生でもらう遺物パックは34個。

**【訂正】到達章の数字は、まだ出せません。**
「1周目で第8章」「2周目で第12章」と一度書きましたが、**どちらも誤りでした。**
測定の打ち切り時間を30秒まで延ばしたら、**転生なしで第16章（測定の上限）まで到達**しました。
止まっていたのは壁ではなく、**測定の打ち切り**です。

つまり**いまの敵の強さは、想定よりかなり緩い**ということになります。
「1周目で第6章が壁」という設計に対して、転生しなくても16章以上行けています。

## ver 0920x

### 転生で残る強さが、到達した深さに追いつくようになりました

これまで**転生しても、既に抜けた章がちっとも楽になりませんでした。**

効果量を上げて解こうとしましたが、**ほんの少し動かすだけで「全然足りない」と

そこで**役割を分けました。**

| | 役割 |
|---|---|
| **土台** | **桁を作る。** 到達した深さから自動で決まる |
| **遺物カード** | **色付け。** どのビルドに寄せるかを変える |

結果、**どの周でも土台が必要ぴったり**になり、遺物の上乗せは ×13〜19.6 で頭打ちします。
引きが悪くても既に抜けた章は必ず楽になり、引きが良ければその周がさらに楽になります。

### 遺物の累乗をやめました

上限が無いと、9周ぶん集めたときに ×480 まで伸びていました。

ダメージ +100〜300% ／ 発射レート +50〜80% ／ コイン +100〜200%（種類ごと）。

### 転生でもらえる遺物パックを増やしました

以前は6章突破しても7パック（21枚）でした。土台が必要とする量から逆算して、
**初回転生で33パック、以降は20パック前後**にしています。

### 転生の回数と章の割り振りを直しました

前は終盤の2周が2章・1章しか進まず、**恒久成長だけで足りてしまって自力で登る意味がありませんでした。**

**6/9/12/15/18/21/24/27/30 に変更**（第1周が6章、以降は毎周3章ちょうど、転生8回）。
どの周も「自力で積む必要 ×5.67 ／ 積める ×28 ／ 余裕 ×5」で揃います。

## ver 0920w

### 30章になりました

5ステージだった本編を **30章**に増やしました。マップは生成しています。

- **型は章ごとに固定**（一本道 → 分岐 → 螺旋・島 → 三叉 → 広間 → 混成）
- **乱数の種は章番号**。何周目でも同じマップです
- 生成したものは全部検査に通しています（経路の長さ・置ける地面の数・十字砲火が組めるか）。
  **30章すべて合格**（地面157〜225 / 十字砲火155〜190 / 経路長20〜48）

新しい武器は**平均3章に1つ**出ます。
スナイパー2章／ミサイル5章／テスラ8章／火炎放射器11章／毒ガス14章／凍結17章／迫撃砲20章。

### 敵の強さの伸び方を引き直しました

| | 前 | 後 |

### 敵の数と、湧き方

敵の数は **150ウェーブを通して 20体 → 200体の直線**にしました。
数は処理落ちと画面の見やすさに直結するので、指数では増やしません。

湧き方の式も変えました。前は「間隔 × 減衰」で持っていたのですが、
**これは敵の数と噛み合いません。** 数が増えると湧き時間が勝手に伸び、
数の少ない序盤は逆に一気に湧いて処理しきれませんでした
（第1章が「21体が1.3秒で全部湧く」状態で、漏れがちょうどライフぶん溜まって毎回死にました）。

**「湧き終わるまでの秒数」で持つようにしました（14秒）。**
敵が何体いても、ウェーブの前半は必ずこの長さです。

### 敵がどっと来るようになりました

ウェーブの**67%が「敵が湧くのを待っているだけ」の時間**でした。

## ver 0920q ＋ 指定攻撃の作り直し

### 指定攻撃が「円に降らせる」ものになりました

ミサイル・迫撃砲・泡の3つを作り直しました。

```
盤面に円を置く → その円の中のランダムな点へ砲弾が降る
```

- **着弾まで当たり判定がありません。** 敵も壁も素通りします
- だから**射線を持たず、スナイパーやガトリングが欲しい地面を譲れます**
- 角度の縛りを撤廃。制約は射程だけで、壁の向こうにも置けます
- 射界のつまみが、そのまま**着弾円の大きさ**になります

ミサイルを「長射程」から「指定攻撃」へ移しました。
