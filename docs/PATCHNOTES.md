# INKURIMENT パッチノート

遊べます → `https://towerinkuri.vercel.app/`

版は**ホーム画面の右上**（`ver 0920v` のように出ます）。
「更新されていない気がする」ときは、そこの文字とこのノートの見出しを見比べてください。

**書き方の決まり**

- 新しいものが上
- **プレイヤーから見て何が変わったか**を先に書く。実装の話は後ろ
- 数字を書くときは**実測値だけ**。「たぶん速くなった」は書かない
- 直した不具合は、**どう壊れていたか**も書く（同じ壊れ方を繰り返さないため）

## ver 0920v

### 敵がどっと来るようになりました

ウェーブの**67%が「敵が湧くのを待っているだけ」の時間**でした。
ひどいところでは「湧き35.1秒 / 倒すの8.7秒」で、8割が待ち時間です。

湧きを詰めて、空いた時間を**敵の数**に振り替えました。

| | 前 | 後 |
|---|---|---|
| ウェーブの長さ | 30.7秒 | **23.4秒** |
| うち待ち時間 | **67%** | **50%** |
| 1秒あたりの撃破 | 9.4体 | **17.1体** |
| 1ウェーブの敵の数 | — | **約2倍** |

**敵の数を2倍にしても、ウェーブは3秒しか伸びず、難しさも変わりません**（測定器で5ステージ通し、どちらも5/5突破・試行回数も同じ）。
待っていた時間が、そのまま戦闘に変わっています。

処理の重さも見ています。同時に敵182体で、1フレーム平均 0.43ms（60fpsに対して39倍の余裕）。

### パックが「転生で開くもの」になりました

これまで**遺物パックが最初から開いていました。**
遺物は転生でしか手に入らない永続強化なのに、転生を知る前に触れてしまう状態で、
長い時間をかけて集めるはずのものを序盤で食い切っていました。

解放の条件を、ステージ数から**転生した回数**に移しました。

| パック | 前 | 後 |
|---|---|---|
| 基本 | 最初から1個持っている | **2ステージ突破** |
| **遺物** | **最初から** | **初めて転生したとき** |
| 兵装 | 1ステージ突破 | 転生2回 |
| 化学 | 2ステージ突破 | 転生3回 |
| 連携 | 2ステージ突破 | 転生4回 |

**まだ開いていないパックが報酬に出たときは、消えずにコインへ振り替わります。**

1周で集まるカードは **17〜19種 / 84種**（前は13〜33種、多いときは32種）。

## ver 0920u

### ボスを廃止しました

**5ステージすべてでボスの撃破数が0**でした。毎回漏れてライフを5持っていくだけで、
ボスのコイン報酬は一度も支払われていません。

原因は「最終ウェーブの**最初の1体**」として湧いていたことです。
盤面に他の敵が1体もいない状態で、首を振っている砲身の前を素通りしていました。
出す順番を「そのウェーブの最後」に変えても、7体中1体しか倒せませんでした。

**「倒せない1体に必ず税金を取られる」以上の役をしていなかった**ので、仕組みごと外しました。

## ver 0920t

### 転生2回でゲームが壊れる件を直しました

原因は2つありました。

1. **「初期投資」が、設置枠のレベルまで底上げしていた。**
   設置枠は火力・カバー範囲・漏れにくさが同時に増えて、他の全強化と掛け算になります。
   **踏破したステージ数以外では絶対に増えない**ようにしました
2. **「常設基盤（どの武器も置ける数 +1）」は、実は何もしていなかった。**
   集計側が読んでおらず、説明文だけが嘘をついている状態でした。
   ライフ+6 の「常設装甲」に変えました

実測（スキル0段の無強化プレイ）：遺物なし 0/5 ／ 初期投資1枚 0/5 ／ **初期投資3枚 1/5**。

### パックをまとめて開けられます

「×N」ボタンで、持っているぶんを一度に開けます。中身は1枚ずつ開けたときと完全に同じです。
換装だけは選ぶ必要があるので、出た回数ぶん順番に出ます。

### スマホの操作

ダブルタップの拡大と、長押しで出る青い選択・コピーの吹き出しを止めました。

## ver 0920s

### 武器の見た目を作りました

12種が「色の違う丸＋棒」だったのをやめ、**形で見分けられる**ようにしました。
六角の台座＋武器ごとの砲塔で、撃った瞬間に砲身が後退します。
3文字の略号は準備フェーズだけ出して、戦闘中は形だけで読ませます。

### 設置枠はお金で前借りできなくなりました

設置枠は他の強化と性質が違って、**火力もカバー範囲も漏れにくさも同時に増え、
しかも全部と掛け算**になります。それが2〜3ステージ目に全部買い切れていました。

**踏破したステージ数ぶんしか伸ばせません。**
実測で、この縛りだけなら難しさはほとんど変わりません（5/5突破・21.1分）。

### 武器ごとに置ける数を見直しました

1基あたりの価値を実測してから振り直しました（撃破数は敵の供給数で頭打ちになるので、
「漏れをどれだけ止めたか」で測っています）。

1基だけで止めた割合：刀98% / 火炎89% / 毒ガス60% / 泡56% / 迫撃砲42% /
手裏剣32% / ガトリング21% / スナイパー21% / テスラ11% / ミサイル5% / 触手4% / 凍結3%

### コインの増え方

「集金効率」が累乗かつ上限なしで、実測で **Lv39・×153倍**まで伸びていました。
1ステージの稼ぎが ×25.7 / ×6.4 / ×38.1 と暴れていた原因です。加算に変えました。

### 湧き口に置くのが正解、ではなくなりました

指定攻撃に射線を持たせなかったので、**敵が必ず・常に・最大密度でいる湧き口**が
無条件の最適解になっていました。

禁止せず、**奥で倒すほど儲かる**ようにしました（コアの目の前 ×2.2 / 湧き口 ×1.0）。

### ツリーが深くなりました

上限のあるノードが21個中11個も1周で打ち止めになっていたので、
火力・射程・レート・範囲の上限を外し、値段で止める形にしました（上限つきは13個に）。

## ver 0920r

### 換装が何なのか分かるようになりました

「何と何を入れ替えるのか」「選ばなかったらどこで変えるのか」が伝わらない状態でした。

- **手に入れた部品は手持ちに残り、スキルツリーの節をタップすればいつでも付け外しできます。**
  元の効き方にも戻せます
- パックの3択に、**入れ替わる前と後を両方**出すようにしました。どの節に刺さるかも出ます
- 「選ばなかったらどうなるか」をその場に書きました

### 射界を広げるのが得になるカード

広げるのは集弾率が落ちるだけの一方通行でした。広さ自体を利益に変える道を足しています。

| | |
|---|---|
| **多銃身** | 射界を広げているほど同時発射が増える（最大+3） |
| **暴発装薬** | 集弾率が最低で固定される代わりに、広げているほどダメージ（最大 ×1.8） |
| **薙ぎ払い** | 手裏剣。射界を広げているほどダメージ（最大 ×1.6） |

実測（ガトリング1基・150秒・3回平均）：多銃身で「広げる有利」が 1.34倍 → **1.95倍**。

## ver 0920q ＋ 指定攻撃の作り直し

### 指定攻撃が「円に降らせる」ものになりました

ミサイル・迫撃砲・泡の3つを作り直しました。

```
盤面に円を置く → その円の中のランダムな点へ砲弾が降る
```

- **着弾まで当たり判定がありません。** 敵も壁も素通りします
- だから**射線を持たず、スナイパーやガトリングが欲しい地面を譲れます**
- 角度の縛りを撤廃。制約は射程だけで、壁の向こうにも置けます
- 射界のつまみが、そのまま**着弾円の大きさ**になります

ミサイルを「長射程」から「指定攻撃」へ移しました。

### 直した不具合

| | どう壊れていたか |
|---|---|
| **加熱暴走** | 撃った回数で溜めていたので、撃ちっぱなしにした時点で敵がいなくても常に最大だった。当てているあいだだけ溜まる形にし、上限をつけた |
| **画面が一生揺れる** | 上限は26pxで存在したが、撃つたびに積むので常に張り付いていた。日常3px / 一発ものの衝撃16px の2段に |
| **触手が上に弾き飛ばす** | 「上に飛ばす」処理は書いていなかった。道を外れた瞬間に行き先がコア直通へ切り替わり、その逆＝壁を無視してコアの真逆へ直進していた。コアが下のマップなので上に見えていた。道の上・通れるタイルへだけ下げるようにした（壁抜け0回） |
