## 5. ゲーム体験の問題点

### コードと実測から判断できるもの

| 観点 | 判断 | 根拠 |
|---|---|---|
| **戦闘中の待ち時間** | 序盤・中盤は解決済み（比 0.43 / 0.68）。**終盤だけ待ちが上回る（1.18）。しかも強いビルドだけ**（待ち率は10%〜65%まで開く） | 実測 |
| **配置の戦略性** | **問題あり。十字砲火が組める地面が全ステージ86〜99%で、どこに置いても組める。**「どのタイルを選ぶか」がほぼ問われていない | マップ構造の実測 |
| **武器ごとの役割** | 6カテゴリに分かれ、スキルもカテゴリ単位。役割分担は成立している | コード |
| **カードによるビルドの多様性** | **成立している。**パックを開けると全ビルドで到達が伸びた（標準31.1→26.7分、非効率 2/5→3/5） | 実測 |
| **シナジーの成立しやすさ** | **問題あり。**所持していても5ウェーブでは引けない。6回連続の挑戦でシナジーカード0枚 | 実測 |
| **インクリメンタル成長の実感** | 数字は出ている（ライフ24→312、火力×1→×477,176）。**実感できるかは別問題** | 実測 |
| **転生の動機** | **成立している。**奥まで行ってから転生するほうがパック効率2.1倍 | 実測 |
| **カードパック収集の動機** | **問題あり。**主要経路の完璧クリアが初回突破の流れでは取れない。基本パックは重複だらけ | 実測 |

### 実プレイによる確認が必要なもの

| 観点 | 確認すべき内容 |
|---|---|
| 成長の実感 | 「ライフ24→312」が**気持ちよく感じられるか**。数字が大きくなること自体が報酬になっているか |
| ヒートマップの実用性 | 溜まり場と漏れルートの表示を見て、**実際に置き直したくなるか**。今回の通しでは盤面が赤枠だらけで読みにくかった |

| ウェーブ間の間 | ボタンを押すまで進まない設計が、**考える時間として機能しているか／単に面倒か** |
| 初見の難しさ | 今回の通しでは**何も強化せずに始めるとウェーブ2で死にました**（ライフ24が1ウェーブで10減る）。これが「もう一度やろう」になるか「理不尽」になるか |

## 9. 総括

### 現時点で最も完成を妨げている問題

**シミュレータが「扇の幅（集弾率）」と「ウェーブ間の再配置」を再現していないこと。**

このゲームは「正面扇の射界を絞って集弾率を上げ、ウェーブ間に置き直して射線を組む」ことを中心に設計されています。しかし測定器はそのどちらも一度もしていません。

つまり現在の実測はすべて「扇は初期値のまま、置きっぱなし」のプレイヤーの数字です。この状態で難易度を調整すると、**「配置を工夫すれば勝てる難易度」を「数字が足りない難易度」と誤認して、必要のない緩和をしてしまいます。**

これまでに測定器の欠陥を8つ見つけて直してきましたが、これが9つ目にして一番大きいものです。
